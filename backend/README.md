# Portfolio Backend

一个Python后端项目

## 项目结构

```
portfilio-end/
├── src/              # 源代码目录
├── tests/            # 测试文件目录
├── requirements.txt  # 项目依赖
├── .gitignore       # Git忽略文件
└── main.py          # 程序入口
```

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行项目

```bash
python main.py
```

## 开发说明

请将源代码放在 `src/` 目录下，测试代码放在 `tests/` 目录下。
