# 混合动量选择器 / 资产选择 — 前后端涉及代码清单

本文档列出与**混合动量选择器**、**资产选择**相关的新增或修改所涉及的**前端（portfolio）**与**后端（portfolio-end）**代码文件及职责说明。

---

## 一、后端（portfolio-end）

### 1. 资产选择模块 `app/selection/`

| 文件 | 职责 |
|------|------|
| `app/selection/__init__.py` | 资产选择模块入口说明 |
| `app/selection/types.py` | `SelectionResult` 等类型定义（含 `tags`: both/momentum/reversal） |
| **`app/selection/formula/advanced_momentum_factors.py`** | **7+1 核心**：MOM/MACD/POSI/SMOM 与 SKEW 因子计算；`compute_advanced_momentum_scores`、`select_momentum_and_reversal_assets`；有效资产「截取数据但不筛选」逻辑（effective_min） |
| `app/selection/formula/momentum_factors.py` | 基础动量因子（可选，供其他选择器用） |
| **`app/selection/selectors/momentum_reversal.py`** | **混合动量选择器**：`MomentumReversalSelector`，参数 schema（n_momentum=7, n_reversal=1, min_history_days=260, momentum_windows, reversal_windows），`select()` 调用 `select_momentum_and_reversal_assets` 并产出 `tags`；`_log_selection_params`、`_log_ranking_info` 打印接收/执行/默认参数 |
| `app/selection/selectors/momentum.py` | 纯动量选择器（非 7+1） |
| `app/selection/selectors/base.py` | 选择器基类 `BaseAssetSelector` |
| **`app/selection/services/selection_service.py`** | 选择器注册与调度：`register("momentum_reversal", MomentumReversalSelector)`，`select_assets(selector_type, prices, n_assets, **params)` |

### 2. 回测与策略适配 `app/backtesting/`

| 文件 | 职责 |
|------|------|
| **`app/backtesting/strategy_api.py`** | **资产选择与权重的桥梁**：`StrategyAdapterWithSelection`；将 hybrid/reversal/momentum_reversal 统一为 `momentum_reversal`；为 momentum_reversal 设置默认 selection_params（n_momentum=7, n_reversal=1, momentum_windows, reversal_windows, min_history_days）；调用 `selection_service.select_assets`；取 `selection_result.tags` 作为 `_asset_tags` 传入策略 `allocate`；未选中资产权重置 0；`_log_rebalance_weights` 打印每次调仓权重 |

### 3. API 层 `app/api/`

| 文件 | 职责 |
|------|------|
| **`app/api/backtests.py`** | 回测请求处理：解析 `selector_type`，将 hybrid/reversal/momentum_reversal 映射为 `momentum_reversal`；构造 `selection_info`（selector_type, n_assets, selection_params），其中 n_momentum=7、n_reversal=1、min_history_days、momentum_windows、reversal_windows；单资产最大权重的编制规则默认值（zy_document_max_weights）；run-by-model 时把 selection_info 传给引擎 |
| `app/api/strategy_model.py` | 策略/模型 CRUD；若涉及模型配置中的 selector_type、asset_selection_count 等字段的读写，会与资产选择配置相关 |

### 4. 策略与权重计算 `app/strategies/`

| 文件 | 职责 |
|------|------|
| **`app/strategies/models/risk_budget_target_vol.py`** | 风险预算+目标波动率策略：读取 `_asset_tags`，按 both/momentum/reversal 分配 risk_budget_both(2/8)、risk_budget_single(1/8)；有效资产「截取数据但不筛选」effective_min_history_days；vol_windows=[22,65,130]、target_vol=0.05 |
| `app/strategies/formula/rolling_volatility.py` | 22/65/130 窗口滚动波动率，取 max（与编制规则一致） |

### 5. 配置与常量

| 文件 | 职责 |
|------|------|
| `app/config/zy_document_max_weights.py` | 浙银理财编制规则：按资产代码/名称的单资产最大权重表；前端未传时 backtests 用此表填充 max_weight_dict |

## 二、前端（portfolio）

### 1. 策略模型表单与详情

| 文件 | 职责 |
|------|------|
| **`src/views/strategy/StrategyModelForm.vue`** | 新建/编辑策略：资产选择策略区域；`selector_type`（含选项「混合动量选择器」value=`hybrid`）；`asset_selection_count`（选择资产数量）；`enable_momentum_selection`；提交时把 selector_type、asset_selection_count 等写入 strategy_params |

### 2. 回测执行与结果

| 文件 | 职责 |
|------|------|
| **`src/views/strategy/BacktestExecution.vue`** | 单策略/多策略回测页：动量资产选择器参数区块；`form.selector_type`（含「混合动量选择器」value=`hybrid`）；`form.asset_selection_count`；资产池点选、已选数量校验、`selected_asset_codes`；多策略时每策略的 selector_type、asset_selection_count；回测请求携带上述参数 |

### 3. 接口与状态

| 文件 | 职责 |
|------|------|
| **`src/api/strategy.js`** | 策略/回测 API：创建/更新策略、发起回测等请求体中含有 `strategy_params.selector_type`、`strategy_params.asset_selection_count`、`strategy_params.selected_asset_codes` 等 |
| `src/store/modules/strategy.js` | 策略相关 state/actions，若缓存或传递 selector_type、asset_selection_count 则与此相关 |

## 三、前后端参数对应关系（混合动量）

| 前端字段（portfolio） | 后端接收/使用（portfolio-end） |
|------------------------|--------------------------------|
| `selector_type: "hybrid"` | API/strategy_api 映射为 `selector_type="momentum_reversal"`，执行 7+1 选择器 |
| `asset_selection_count` | 用于 n_assets；混合动量时后端用 n_momentum+n_reversal（7+1）覆盖，不按该数字截断 7+1 结果 |
| `selected_asset_codes` | 可选；若传则作为候选池或指定参与计算的资产，后端在 backtests 中可据此过滤/约束 |
| `strategy_params.n_momentum` / `n_reversal` | 回测请求与模型配置中传入，默认 7、1；selection_params 与 backtests 使用 |
| `strategy_params.min_history_days` / `momentum_windows` / `reversal_windows` | 传入 selection_params，选择器与因子计算使用 |
