# 0316 异常净值/价格情况 BUG 修复说明

**修复日期**：2025-03-16  
**影响范围**：回测绩效（年化收益率、波动率等）、净值曲线  
**修复策略**：两层防护——价格层清洗 + 净值层填充

---

## 一、问题描述

回测结果中出现**年化收益率、波动率异常**的情况，表现为：

- 年化收益率或波动率数值明显不合理（过高、过低或极端值）；
- 原因多为**个别日期、个别资产**的行情或中间数据存在异常取值（如缺失、错误、单日涨跌过大），导致：
  - 组合净值在单日出现异常跳变；
  - 基于净值序列计算的日收益率出现极端值；
  - 进而使年化收益率、年化波动率、夏普比率等指标失真。

---

## 二、修复思路

采用**两层防护**，既在数据源头上减轻异常，又在绩效计算前对净值做兜底：

1. **价格层**：在回测使用的**价格矩阵**上，对单资产单日异常涨跌做填充（用前一日价格），从源头平滑净值。
2. **净值层**：在**绩效计算**使用的净值序列上，对单日净值异常跳变做填充（用前一日净值），保证年化收益、波动率等指标不被单日异常拉偏。

异常判定统一采用**单日涨跌幅阈值**：超过阈值视为异常，用**最近一日（前一日）的净值/价格**进行填充。

---

## 三、修改说明

### 3.1 净值层：绩效计算前对净值做异常填充

**文件**：`app/backtesting/analytics.py`

**新增常量**：

```python
# 单日净值涨跌幅超过此阈值视为异常，用前一日净值填充
MAX_DAILY_NAV_CHANGE = 0.5  # 50%
```

**逻辑说明**：

- 在 `PerformanceAnalyzer.from_results()` 中，对由 snapshots 得到的 `total_values`（净值序列）：
  1. 先做原有 nan/inf 的 `replace` 与 `ffill().bfill()`；
  2. **新增**：若序列长度 ≥ 2，则计算日环比 `pct_change()`，并取前一日净值 `shift(1)`；
  3. 仅当「前一日净值有效（> 1e-12）」且「当日涨跌幅绝对值 > MAX_DAILY_NAV_CHANGE」时，将该日视为异常；
  4. 异常日的净值用**前一日净值**覆盖：`total_values.where(~abnormal, prev)`，再执行一次 `ffill().bfill()`；
  5. 后续收益率、波动率、年化收益等均基于该处理后的净值序列计算。

**效果**：单日异常净值被替换为前一日净值（相当于该日收益率为 0），避免年化收益率、波动率、夏普等被单日极端值扭曲。

---

### 3.2 价格层：回测前对价格矩阵做异常填充

**文件**：`app/backtesting/data_feed.py`

**新增函数**：

```python
def sanitize_prices(
    prices: pd.DataFrame,
    max_daily_pct_change: float = _MAX_DAILY_PRICE_CHANGE  # 默认 0.5
) -> pd.DataFrame
```

**逻辑说明**：

1. 若 `prices` 为空或 None，直接返回；
2. 拷贝 `prices`，将 inf/-inf 替换为 nan，再按列 `ffill().bfill()`；
3. **按列**处理：对每一列（资产）计算 `pct_change()`，若「前一日价格有效」且「当日涨跌幅绝对值 > max_daily_pct_change」，则将该日该资产价格替换为**前一日价格**；
4. 再整体做一次 `ffill().bfill()`，返回新 DataFrame（不修改入参）。

**调用位置**：在 `DataFeed.from_market_service()` 中，取得 `get_price_matrix_with_lookback` 返回的 `prices` 后，执行：

```python
prices = sanitize_prices(prices)
return cls(prices=prices, config=config)
```

**效果**：所有通过 `DataFeed.from_market_service` 获取数据的回测（含混合动量等）使用的都是经异常填充后的价格，从源头降低单日单资产异常对净值曲线的影响。

---

## 四、涉及文件与配置

| 文件 | 修改内容 |
|------|----------|
| `app/backtesting/analytics.py` | 新增 `MAX_DAILY_NAV_CHANGE`；在 `from_results` 中对净值序列做异常检测与按前一日净值填充 |
| `app/backtesting/data_feed.py` | 新增 `sanitize_prices()`；在 `from_market_service()` 中调用 `sanitize_prices(prices)` |

**当前阈值**：

- 净值与价格均使用 **50%（0.5）** 作为单日涨跌幅上限；
- 需调整时：analytics 中改 `MAX_DAILY_NAV_CHANGE`，data_feed 中改 `_MAX_DAILY_PRICE_CHANGE` 或 `sanitize_prices` 的默认参数即可。

---

## 五、使用与注意

- **无需配置**：修复随代码生效，所有使用 `DataFeed.from_market_service` 的回测及所有使用 `PerformanceAnalyzer.from_results` 的绩效计算都会自动应用上述逻辑。
- **阈值含义**：单日涨跌幅（按前一日基数）超过 50% 的净值/价格会被视为异常并以前一日值填充；若业务上希望更严（如 30%）或更松（如 100%），可统一调整两处常量/默认参数。
- **与现有逻辑的关系**：nan/inf 的 ffill/bfill 以及绩效指标的 clamp（如年化波动率上限、收益率范围等）保持不变，本修复在此基础上增加「按最近日期净值/价格填充」的异常处理，专门针对单日异常跳变导致的年化收益与波动率失真问题。

---

## 六、总结

| 层级 | 位置 | 做法 |
|------|------|------|
| 价格层 | `data_feed.sanitize_prices` + `DataFeed.from_market_service` | 单资产单日涨跌幅 > 阈值 → 用前一日价格填充 |
| 净值层 | `analytics.PerformanceAnalyzer.from_results` | 单日净值涨跌幅 > 阈值 → 用前一日净值填充 |

通过上述两层处理，在存在**异常日期、异常资产取值**时，系统会按**最近日期的净值/价格**进行填充，从而抑制年化收益率与波动率的异常波动，修复 0316 涉及的异常净值价格 BUG。
