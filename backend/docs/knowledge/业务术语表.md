# 业务术语表

本文档收录系统投研平台的核心业务术语与缩写定义，供新成员入门、Agent 检索与文档交叉引用使用。术语按主题分组：策略架构类、配置模型类、风控类、组合与运维类。

## 一、策略架构类

### 三层正交架构
- 定义：策略模型的标准结构 = 选择层（Selection，选什么资产）→ 分配层（Allocation，怎么定权）→ 控制层（Control，仓位缩放/风控）。三层职责正交、可插拔组合。
- 别名：Selection/Allocation/Control、SAC 架构

### 选择器（Selector）
- 定义：选择层组件，输出 SelectionResult（信号分数/0-1 掩码/权重种子）。系统共 6 个：动量+反转(7+1)、夏普率、截面动量、截面多空、趋势跟踪、ETF轮动。
- 别名：资产选择器

### 分配器（Allocator）
- 定义：分配层组件，统一入口 `allocate(prices, **params) -> Series`，输出资产权重。系统策略库共 12 个配置模型（详见《系统策略库配置模型详解》）。
- 别名：配置模型、策略模型

### 控制器（Monitor）
- 定义：控制层组件，对组合权重做波动率管理缩放。系统共 2 个：RollingVolMonitor（多窗口触发式）、DualWindowVolMonitor（双窗口连续式）。
- 别名：波动率监控器、风控器

### Composition（组合配置）
- 定义：策略模型中描述"选择器 × 分配器 × 控制器"组合方式的配置结构，是三层可插拔的声明入口。

### Schema 驱动表单
- 定义：前端参数渲染范式——后端模型通过 `get_param_schema()` 声明参数（名称/类型/默认值/分组/联动条件），前端据此动态渲染表单，无需逐策略写死界面。
- 别名：参数 Schema、ParamSchema

## 二、配置模型类

### 风险平价（ERC）
- 定义：等风险贡献（Equal Risk Contribution）配置，各资产对组合总风险的贡献相等，SLSQP 数值求解。系统模型代码 `risk_parity`，显示名称"风险平价"（项目内统一术语，不再用"等风险贡献"作为正式名）。核心约束仅 Σw=1，不加单资产权重上限。
- 别名：ERC、等风险贡献

### 因子风险平价（Factor RP）
- 定义：先对资产收益做 PCA 分解提取风险因子，在因子空间做等风险暴露，再映射回资产权重。解决资产高相关下风险平价失真问题。系统模型代码 `factor_risk_parity`，因子提取组件为 `PcaFactorModel`。
- 别名：PCA 风险平价

### 类雪球（Snowball-like）
- 定义：通过蒙特卡洛定价计算雪球期权 Delta、动态调整标的仓位以复制雪球结构收益的策略类别。系统实现为 `snowball_delta_hedge`，支持 KO（敲出赚票息）/KI（敲入承担下跌）/到期结算的合约生命周期管理，每日连续调仓，是策略库唯一负凸台策略。
- 别名：雪球结构、模拟雪球、Delta 对冲策略

### KO / KI
- 定义：雪球合约的两个障碍事件。KO（Knock-Out，敲出）：标的涨破上障碍，合约提前结束，赚取票息；KI（Knock-In，敲入）：标的跌破下障碍，投资者承担下跌损失。
- 别名：敲出 / 敲入

### Delta 对冲
- 定义：按期权 Delta（价格敏感度）动态调整标的持仓以对冲方向性风险。系统雪球模型用数值微分计算 Delta，仓位系数 delta_coef ∈ [-1, 1]，允许负权重。

### 均值-方差（MVO）
- 定义：Markowitz 均值-方差优化，在预期收益与协方差估计下求解有效前沿组合。对收益估计敏感，属误差放大器。系统模型代码 `mean_variance`。

### Black-Litterman（BL）
- 定义：贝叶斯资产配置框架：市场均衡隐含收益为先验，融合主观观点得后验收益分布再优化。系统模型代码 `black_litterman`。

### 风险预算（RB）
- 定义：风险平价的推广，按指定比例分配各资产风险贡献（而非相等）。系统模型代码 `risk_budget`。

### 协方差-夏普优化（CSO）
- 定义：风险平价框架叠加夏普比增强项的混合模型，lambda_sharpe=0 时退化为纯风险平价。系统模型代码 `enhanced_risk_parity`。

### 目标波动率预算（TVB）
- 定义：编制规则模型，w = 预算 × σ_target / σ_realized，通过 budget_source 切换预算来源。系统模型代码 `vol_scaled_budget`，是单资产权重上限约束的合法适用对象。

### 固定比例组合（46 / 64 等行业惯称）
- 定义：业界对"固定权重股债组合"的数字惯称：前一位数字是股票权重、后一位是债券权重。如"46 模型"= 股 40% + 债 60%，"64 组合"= 股 60% + 债 40%。此类策略无优化计算、权重长期固定（可定期再平衡回目标比例），是基准组合与对照实验的常用参照。
- 别名：46 模型、股债 46、64 组合、传统股债组合
- **系统构建惯例**：一律用 `manual_allocation`（手动配置）模板实例化，`parameters.manual_weights` 按目标比例填写（如 46 = 股 0.4 / 债 0.6，权重总和为 1）。**泛化规则**：遇到任何"固定比例、不做优化"的口语表述（如永久组合、懒人组合等），先识别其目标权重，再用 manual_allocation 构建；不确定的比例先向用户确认。

## 三、风控类

### 双轨波动率机制
- 定义：系统中并存的两套波动率控制语义。①控制器层（BaseMonitor 子类）：杠杆 = min(1.0, target/vol)，只降不升，是"风险阀"；②回测引擎层 vol_targeting：双向定标 clip(target/vol, 0.1, 5.0)，可加杠杆至 5 倍，是"杠杆放大器"。二者语义冲突，配置时必须明确区分。

### 阈值触发式控波
- 定义：仅当实时波动超过阈值时才调整仓位（缩到目标），否则不干预的波动率控制形态；与每日连续定标（lev = target/vol 持续压缩敞口）相对。RollingVolMonitor 为触发式，DualWindowVolMonitor 为连续式。
- 别名：触发式控波、风险阀

### 双窗口波动率估计
- 定义：同时用短窗口（如 20 日）与长窗口（如 60 日）估计波动率并取平均的稳健估计法，支持 rolling / ewma 两种算法。DualWindowVolMonitor 的核心机制。
- 别名：双层控波、vol targeting（泛指）

## 四、组合与运维类

### 四象限策略
- 定义：一种产品层组合模型，包含四个象限策略（如 CBA11321.CS、511360.SH 等），每个象限有独立侧重策略、信号触发条件、放大倍数、窗口等参数，通过动态调权标签管理权重。前端创建/编辑界面支持完整回显与修改。
- 别名：产品层组合

### 监控注册
- 定义：在 `monitored_strategies` 集合中为策略模型建立监控实例的记录，含 source_ref（指向模型 ID）、创建时间等。监控引擎不支持 portfolio_composite 类型（母组合），对母组合点监控会产生无效注册并反复 404。
- 别名：监控实例、monitor_id

### 建仓日（inception_date）
- 定义：策略或组合开始计算的起始日期。系统日常监控从建仓日至今逐日推演。建仓日为 None 的模型需按业务口径补设。

### 策略系统化（Strategy Onboarding）
- 定义：将研究原型策略转化为系统生产模型的标准流程：原型阶段模块化（signal/allocator/risk_control 分文件、config 统一管理、data_loader 唯一 IO）→ 落地决策树（逻辑差异新建、简单增强合入原模块且 leverage=1 可回退）→ 复合体拆解 → 零隐藏参数 → 前端配置化。
- 别名：策略落库、策略入系统

### 复合体拆解法
- 定义：策略系统化规范中的判断方法：若原型代码先计算多个子指数收益再按权重线性组合（收益层复合），则系统应拆为"多个子策略模型 + 一个组合模型"，而非注册为单一 allocation 策略。识别信号：`raw_ret = w1 × ret_A + w2 × ret_B` 形式的收益合成代码。

### 年化因子（annualization_factor）
- 定义：将日频波动率折算为年化的乘数，系统默认 260 交易日（√260）。

### 信号生效延迟（T+delay）
- 定义：信号日与实际生效日之间的交易日间隔。典型为 T+1/T+2：T 日收盘算信号，T+1 或 T+2 日按新权重执行，避免未来函数。

## 五、使用指引

- Agent 检索：知识库检索采用 $regex 中文匹配，术语的别名同样可命中；
- 术语冲突处理：若代码行为与本文档定义不符，以代码为准并反馈修订本文档；
- 新增术语：随新功能沉淀术语时，补充到对应分组并登记别名。
