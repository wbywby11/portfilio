# 系统架构总览

本文档是量化资产配置平台的架构总入口，描述前后端技术栈、业务域划分、依赖方向与核心数据流。新成员入门、跨模块开发定位、Agent 理解系统全貌时先读本文档。

## 一、系统组成

```
start-mongodb.bat        本地 MongoDB（端口 27018，数据目录 .mongodb-data，与系统默认 27017 隔离）
portfilio-end            后端：FastAPI 主应用（REST API + 量化引擎 + Agent）
portfilio                前端：Vue2 SPA（Element UI + Vuex + Vue Router + ECharts）
```

- 后端：FastAPI + Uvicorn，PyMongo/Motor 访问 MongoDB，Pandas/NumPy/SciPy/scikit-learn 量化计算，OpenAI SDK + tiktoken 驱动 Agent，loguru 日志；
- 前端：Vue2 + Element UI，VXETable 表格，ECharts 图表，axios 统一请求封装（Bearer Token 注入 + 401/403/超时拦截）。

## 二、后端业务域划分（app/ 目录）

| 子域 | 目录 | 职责 |
|---|---|---|
| 资产与数据 | `api/` + `services/` + `data/` | 资产档案、行情导入、汇率、交易日历、数据资产盘点 |
| 资产选择 | `selection/` | 7 个选择器（动量/夏普/趋势/截面/ETF 轮动/贴水率） |
| 资产配置 | `allocation/` | 12 个配置模型 + 动态加载注册表（详见《系统策略库配置模型详解》） |
| 风险控制 | `control/` | 2 个波动率控制器（详见《选择层与风控层模块说明》） |
| 回测 | `backtesting/` | engine + composition_pipeline + analytics（详见《回测引擎与组合运行机制》） |
| 组合管理 | `portfolio/` | composite_runner 两段式母组合、四象限组件、模拟交易引擎 |
| 日常监控 | `monitor/` | 日级步进 + 信号检测 + 报告生成（详见《日常监控模块说明》） |
| 期权估值 | `options/` | 波动率曲面、欧式/奇异定价、收益凭证估值 |
| AI 助手 | `agent/` | LLM 客户端 + 工具链 + 记忆/知识存储（详见《Agent能力与使用指南》） |
| 公式库 | `formula/` | 收益率、滚动波动率等可复用量化公式 |
| 基础设施 | `config/` | pydantic-settings 配置、数据库连接、集合名常量表、日志装配 |

## 三、分层架构与依赖方向

```
api/（HTTP 路由层，每文件一个 tag）
  ↓
services/（跨模块编排层）
  ↓
domain 子包（selection/allocation/control/backtesting/portfolio/monitor/options/agent）
  ↓
models/ + data/ + config/（Pydantic 模型、数据访问、配置）
```

依赖方向自顶向下，domain 之间通过共享 models/schemas 解耦，禁止反向依赖。

## 四、启动生命周期（main.py lifespan）

1. `load_dotenv()` 加载 `.env` 配置（pydantic-settings 驱动，`case_sensitive=True`、`extra="ignore"`）；
2. `setup_logging()` 装配 loguru（控制台 + `logs/app_YYYY-MM-DD.log` 按天轮转，默认保留 7 天）；
3. 连接 MongoDB（`settings.MONGODB_URL` / `DATABASE_NAME`，默认库 `asset_allocation`）；
4. 初始化内置策略模板（`model_templates` 集合，code 唯一约束）；
5. 扫描数据资产（`_data_asset_registry`：集合规模、记录数、字节数）；
6. 确保知识库索引；
7. uvicorn 按 `API_HOST/API_PORT`（默认 8000）启动。

**启动顺序纪律**：必须先 `start-mongodb.bat` 再启后端，否则 lifespan 初始化报 `ServerSelectionTimeoutError`（WinError 10061 连接被拒）。

## 五、前端结构速览

- 入口 `src/main.js` 注册 ElementUI/VXETable/ECharts；路由按业务域划分（asset/strategy/analysis/options/system/agent），`meta.requiresAuth` + `beforeEach` 守卫鉴权；
- 状态管理按领域拆分 user/asset/strategy/portfolio/monitor/agent 六个 Vuex 子模块；
- 网络层 `src/utils/request.js` 统一封装，各业务 API 在 `src/api/*.js`；
- 页面在 `src/views/` 按域组织，通用组件在 `src/components/`（AgentChatPanel、BacktestMiniChart、SyncProgressDialog 等）；
- 前端端口约定：`VUE_APP_API_PORT` 必须与后端 `API_PORT` 一致。

## 六、配置与环境

- 配置单一来源：`.env`（key=value），权威清单见 `.env.example`；
- 敏感信息（LLM_API_KEY 等）仅环境变量注入，不入库不入码；
- 集合名集中管理：`app/config/collections.py` 以 `COL_*` 常量声明，Service 层禁止硬编码集合名字符串。
