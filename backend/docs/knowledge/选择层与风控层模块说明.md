# 选择层与风控层模块说明

本文档描述系统 Selection（资产选择）层 6 个选择器与 Control（风险控制）层 2 个波动率控制器的机制、参数与选型要点。选择层负责"选什么资产"，风控层负责"仓位怎么压缩"，与 Allocation 层（怎么定权）共同构成策略三层正交架构。

## 一、三层架构定位

```
策略模型 = 选择层(Selection) → 分配层(Allocation) → 控制层(Control)
            选什么资产           怎么定权              仓位缩放/风控
```

- 选择层输出 SelectionResult（信号分数/0-1 掩码/权重种子）；
- 分配层基于选中资产计算权重（见《系统策略库配置模型详解》）；
- 控制层对组合权重做波动率管理缩放。

## 二、选择层：6 个选择器

所有选择器位于 `app/selection/selectors/`，继承 `BaseAssetSelector`，通过 `get_param_schema()` 声明参数供前端渲染。

### 2.1 动量+反转（momentum_reversal，7+1）

**机制**：动量与反转双模式选品，复刻特定指数编制规则（与官方规则第 279、295-299 行一致）：
- 动量通道：MOM / MACD / POSI / SMOM 四个信号选出 7 个资产；
- 反转通道：SKEW（偏度）信号选出 1 个资产；
- 合并为 7+1 共 8 个资产，未入选资产权重为 0。

**信号实现**：高级动量因子公式库 `app/selection/formula/advanced_momentum_factors.py`（含默认窗口 DEFAULT_MOM_WINDOWS / DEFAULT_MACD_WINDOWS / DEFAULT_REVERSAL_WINDOWS）。

### 2.2 夏普率综合打分（sharpe）

**机制**：三窗口夏普综合打分选 TopN：
- 夏普因子公式：SHARP_n = (P_t / P_{t-n} - 1) / std(daily_ret, n)；
- 在 22 / 65 / 260 日三个窗口分别计算并综合打分；
- 选分数最高的 TopN 品种，时点动量（MOM）占优。

### 2.3 截面动量（cross_sectional_momentum）

**机制**：最简截面动量时序选择：
- 以过去 N 日 rolling 累计收益率为动量分数；
- 降序选前 top_n 品种，输出 0/1 选择掩码。

**核心参数**：`momentum_window`（动量回看窗口，默认 20 日）。

**与夏普选择器区别**：夏普选择器使用多窗口 SHARP 复合打分；截面动量仅用简单 rolling 累计收益率。

### 2.4 趋势跟踪（trend_following）

**机制**：每品种独立判断多空方向：
- 计算过去 N 日累计收益，取 sign 作为方向（多/空）；
- 按波动率倒数（inv_vol）加权确定仓位大小；
- 归一化使 sum(|w|) = 1（多空总敞口归一）。

**核心参数**：
- `tf_lookback`：趋势跟踪窗口（交易日），默认 25；
- `tf_threshold`：入场阈值（sigma 倍数），0 = 直接使用方向，默认 0.0。

### 2.5 截面多空（cross_sectional_long_short，50/50）

**机制**：跨品种横截面多空：
- 多窗口累计动量打分；
- 做多动量前 50% 品种、做空后 50% 品种；
- 组内按波动率倒数加权，归一化至 ±0.5（多空各半）。

**月末信号日历**：信号（品种与方向）仅在月末信号日更新，inv_vol 权重每日重算但信号暴露不变，避免调仓频率放大；支持自定义信号日历与价格日历分离，生效日 = 信号日 + delay + 1。

### 2.6 ETF轮动（etf_rotation）

**机制**：ETF 轮动复合打分选品，支持四种子策略通过参数切换（`sub_strategy`）：
- `volatility` 低波动轮动：剔除波动率后 20%，选波动最低的 N 只；
- `return_bias` 收益+低波动：剔除波动率后 20%，选收益前 N 且波动 < 阈值；
- `mixed` 混合打分：低波前 3 + 收益前 2（波动 < 阈值）；
- `breakthrough` 强势突破：涨幅前 30 日剔除波动过大者，选前 N。

## 三、风控层：2 个波动率控制器

控制器位于 `app/control/volatility/`，继承 `BaseMonitor`。**共同语义：只降不升的风险阀**（杠杆 = min(1.0, target/vol)），不做向上加杠杆。

### 3.1 多窗口触发式（rolling_vol / RollingVolMonitor）

**机制**：滚动多窗口估计组合波动率，取多窗口**最大值**作为触发判据；波动超过阈值时触发降杠杆，否则不干预（阈值触发式）。

**核心参数**：
- `vol_windows`：窗口列表，默认 [22, 65, 130] 交易日（兼容旧格式 vol_window_short/medium/long）；
- `target_vol`：目标年化波动率；
- `vol_reset_threshold`：波动率重置触发阈值；
- `min_data_days`：最少历史数据要求，默认 130；
- `annualization_factor`：年化因子，默认 260 交易日；
- `trigger_operator`：触发比较符（'>' 或 '>='，默认 '>'）；
- `fillna_zero`：缺失波动填 0（默认 True，与历史版本一致）。

### 3.2 双窗口连续式（dual_window_vol / DualWindowVolMonitor）

**机制**：短窗口 + 长窗口波动率估计取**平均值**作为当前波动，每日连续计算杠杆压缩敞口（连续式）。

**波动率估计** = （短窗 vol + 长窗 vol）/ 2，支持 rolling（滚动标准差）/ ewma（指数加权）两种估计法（`vol_method`）。

**核心参数**：
- `vc_short`：短窗口，默认 20 交易日；
- `vc_long`：长窗口，默认 60 交易日；
- `target_vol`：目标年化波动率，默认 0.03；
- `vol_reset_threshold`：波动重置阈值，默认 0.06；
- `enable_vol_reset`：是否启用波动重置，默认 True；
- `annualization_factor`：年化因子，默认 260。

### 3.3 两控制器对比与选型

| 维度 | RollingVolMonitor | DualWindowVolMonitor |
|---|---|---|
| 窗口聚合 | 多窗口取最大值 | 双窗口取平均值 |
| 触发方式 | 阈值触发式（超阈值才调整） | 连续式（每日定标） |
| 波动估计 | rolling | rolling / ewma |
| 典型场景 | 预算类策略的风控阀 | 平滑连续的敞口压缩 |

## 四、关键注意事项

1. **双轨波动率机制警示**：控制器层（只降不升的风险阀）与回测引擎层 `vol_targeting`（双向定标、clip(target/vol, 0.1, 5.0)，可加杠杆至 5 倍）语义完全不同，配置策略时必须明确配置的是"风险阀"还是"杠杆放大器"；
2. **命名消歧**："截面动量"（top_n 多头掩码）与"截面多空 (50/50)"（±0.5 多空权重）名称相似但机制不同，选型时勿混淆；
3. **选择器与分配器参数分离**：TF/CS 类信号参数（tf_lookback 等）由选择器层持有，分配层 Schema 不包含，前端在"资产选择"区域配置；
4. **选择器可插拔**：所有选择器经统一注册表暴露，策略模型通过 composition 配置自由组合"选择器 × 分配器 × 控制器"。
