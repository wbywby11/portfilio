# Agent能力与使用指南

本文档描述系统内置 AI 投研助手（Agent）的能力边界、工具清单、写操作确认机制与提问技巧。用户学习如何高效使用 Agent、开发者排查 Agent 行为问题时以本文档为准。

## 一、Agent 定位

Agent 是投研平台内置的研究助手，核心架构为 ReAct 循环（推理→工具调用→观察→再推理），具备：
- **工具调用**：21 个系统工具覆盖数据/策略/组合/监控/报告/知识/记忆；
- **长期记忆**：跨会话记住研究结论、资产别名等（agent_memories 集合）；
- **知识库联动**：自动检索知识库回答策略/业务问题，如实引用、注明来源；
- **写操作保护**：所有改变系统状态的操作必须经确认卡片批准。

## 二、工具清单（21 个）

### 读工具（免确认）

| 工具 | 能力 |
|---|---|
| `query_assets` | 数据库数据集合盘点（记录数/字段/日期范围/新鲜度，数据工程视角） |
| `check_data_quality` | 数据质量检查（重复/缺失/陈旧） |
| `query_dataset` | 数据集探查（元数据 + 预览） |
| `query_import_logs` | 导入日志溯源 |
| `query_data_connectors` | 数据连接器状态 |
| `query_strategies` | 策略模型与模板查询 |
| `query_backtests` | 回测记录与指标查询 |
| `query_portfolios` | 组合与持仓查询 |
| `query_monitors` | 监控状态与日报查询 |
| `query_reports` | 历史报告列表/详情 |
| `search_knowledge` | 知识库检索（关键词+分类+资产过滤） |
| `read_knowledge` | 知识库文档精读 |
| `read_tool_result` | 二次读取大体积工具结果 |

### 写工具（必须确认卡片批准）

| 工具 | 能力 |
|---|---|
| `create_strategy_model` | 创建策略模型实例（指定模板/资产池/参数） |
| `create_portfolio` | 创建组合 |
| `adjust_portfolio` | 调整组合权重/持仓 |
| `run_backtest` | 触发回测（主观配置模型未预设调仓日时自动补期初调仓） |
| `trigger_data_sync` | 触发数据同步 |
| `update_monitor_config` | 更新监控配置 |

### 轻量写工具（免确认）

| 工具 | 能力 |
|---|---|
| `save_report` | 保存分析报告（Markdown 落 reports 集合） |
| `manage_memory` | 写入/更新长期记忆 |

### 工具选型约定（重要）

- **“可投资资产”≠“数据集合”**：为策略/组合挑选底层资产时，用 `query_dataset(dataset='assets')` 查资产主数据（可交易资产清单，含代码/名称/资产类别）；`query_assets` 是数据库数据集合元数据盘点（数据工程视角），**不要**用它选资产，也不要向用户汇报数据集合清单；
- 行情数据在 `asset_prices` 集合（按 asset_code + date 查询）；
- 口语化的策略类型/资产名称，先检索《业务术语表》确认系统对应物再构建。

## 三、确认卡片机制（写操作保护）

1. Agent 决定执行写操作时，先生成**确认卡片**（回显操作类型与全部参数），等待用户批准；
2. 用户可以**确认执行**或**取消**——取消后操作终止、无脏数据落库；
3. 卡片有 TTL 有效期，过期自动失效；刷新页面后待确认卡片可重建；
4. 相同参数的确认 Token 可复用，避免重复弹窗；
5. 确认执行成功后前端会自动发送续跑消息，Agent 基于执行结果继续完成多步任务的剩余步骤（如回测、对比、报告）；
6. 所有写操作执行后记录 `agent_write_logs` 审计日志。

**护栏设计**：`create_strategy_model` 的 template_code 必须在模板注册表内（防编造策略类型），资产代码必须存在于 assets 集合；主观固定权重模板（manual_allocation）的 manual_weights 必须覆盖全部资产且总和为 1。创建的模型自动标记 created_by=agent。

## 四、知识库使用纪律

Agent 遵循知识库使用纪律：涉及策略原理、业务规则的问题**优先检索知识库**；检索无命中时如实告知"知识库未收录"，不编造引用；引用内容注明来源文档。

## 五、提问技巧（用户指南）

**高效提问模式**：
- 复杂任务一次说全："先查知识库了解 X 原理 → 盘点资产并说明选择依据 → 创建策略模型 → 回测 → 对比同类模型 → 写报告"，Agent 会自动编排多工具链路；
- 指明约束："底层资产要有依据，说明为什么选"——Agent 会给出金融工程层面的选择理由；
- 追加细化："报告里加一张净值曲线图"——Agent 支持多轮迭代完善报告。

**Agent 会主动做的事**：
- 数据时效检查：发现行情滞后会主动提示（如"数据截止 07-31，已滞后 20 天"）；
- 能力边界如实告知：做不到的操作会说明原因并给出替代路径；
- 资产不存在时给替代方案：如个股不在多资产体系中，会推荐同类 ETF。

**Agent 不会做的事**：
- 预测市场涨跌（提供历史分析替代）；
- 未经确认执行任何写操作；
- 绕过确认直接改数据库。

## 六、数据存储位置

- 会话与消息：`agent_conversations` / `agent_messages`；
- 报告：`reports`（created_by=agent 标记）；
- 记忆：`agent_memories`（research_conclusion / asset_alias 等分类）；
- 知识库：`agent_knowledge`（前端知识库页面管理，支持 PDF/DOCX/TXT/MD 上传）。
