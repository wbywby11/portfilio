# 系统策略库配置模型详解

本文档完整描述系统 Allocation（资产配置）层策略库中全部 12 个配置模型的定位、数学原理、核心参数与适用场景，涵盖风险平价、因子风险平价、类雪球 Delta 对冲等策略。配置新策略模型实例、选型对比、参数调优时以本文档为准。

## 一、模型总览

策略库按实现方式分为三类：

### 优化驱动型（6 个）——数值求解器计算权重
| 模型代码 | 显示名称 | 一句话定位 |
|---|---|---|
| `risk_parity` | 风险平价 | 等风险贡献（ERC），各资产对组合风险贡献相等 |
| `mean_variance` | 均值-方差优化 | Markowitz 有效前沿，收益与风险的权衡最优 |
| `black_litterman` | Black-Litterman 贝叶斯 | 市场均衡先验 + 主观观点的贝叶斯后验 |
| `risk_budget` | 风险预算 | 按指定预算比例分配风险贡献 |
| `enhanced_risk_parity` | 协方差-夏普优化 | 风险平价框架叠加夏普增强项（CSO） |
| `factor_risk_parity` | 因子风险平价 | PCA 提取风险因子，在因子空间做风险平价 |

### 闭式/规则型（5 个）——公式直接计算权重
| 模型代码 | 显示名称 | 一句话定位 |
|---|---|---|
| `vol_scaled_budget` | 目标波动率预算 | w = 预算 × 目标波动/实际波动，统一编制规则 |
| `etf_cycle_rotation` | 等权轮动 | 选品后 1/N 等权，选择逻辑交给选择器 |
| `signal_weighted` | 信号加权 | 把选择器信号分数直接转化为权重 |
| `manual_allocation` | 手动配置 | 用户直接指定权重，无优化计算 |
| `snowball_delta_hedge` | 类雪球Delta对冲 | 蒙特卡洛定价 + Delta 动态对冲复制雪球结构 |

（另有 `trend_cross_sectional` 为历史遗留壳层，处于待治理状态，不建议新配置使用。）

模型实现按形态分目录：三层组合形态在 `app/allocation/models/`，打包独立形态在 `app/standalone_strategies/<code>/`。统一入口为 `allocate(prices: DataFrame, **params) -> Series`，参数通过 `get_param_schema()` 声明供前端 Schema 驱动表单渲染。

## 二、优化驱动型详解

### 2.1 风险平价（risk_parity / ERC）

**数学本质**：求解使各资产风险贡献相等的权重。资产 i 的风险贡献为 \(RC_i = w_i \cdot (\Sigma w)_i\)，优化目标为使各 \(RC_i\) 相等，约束为权重和等于 1（Σw=1）。

**实现方式**：SLSQP 数值优化求解，是真正的 ERC 优化（非简单的 1/σ 或 1/σ² 定权）。

**核心参数**：
- `lookback_days`：协方差估计回看窗口（交易日）；
- `cov_method`：协方差估计方法（core 参数，显著改变净值曲线）。

**约束原则**：风险平价的核心约束仅为 Σw=1，不应引入单资产权重上限等额外约束——权重上限违背风险平价本质，该约束仅适用于 vol_scaled_budget 等特定编制规则策略。

**适用场景**：追求风险分散、不预测收益方向的稳健配置。

### 2.2 均值-方差优化（mean_variance / MVO）

**数学本质**：Markowitz 现代投资组合理论。给定预期收益向量 μ 与协方差 Σ，求解：
\[
\min_w \; w^T \Sigma w \quad \text{s.t.} \quad w^T \mu \geq r_{target},\; \sum w = 1
\]
或最大化夏普比的等价形式。

**核心参数**：
- `target_return`：目标收益率约束；
- `lookback_days`：收益与协方差估计窗口；
- `risk_free_rate`：无风险利率（夏普计算）；
- `cov_method`：协方差估计方法。

**注意事项**：MVO 对预期收益估计高度敏感（误差放大器），历史收益作 μ 估计易产生极端权重，建议配合权重边界约束使用。

### 2.3 Black-Litterman 贝叶斯（black_litterman）

**数学本质**：Black & Litterman (1992) 框架。以市场均衡隐含收益为先验，融合投资者主观观点，通过贝叶斯推断得到后验收益分布，再做均值-方差优化：
\[
\mu_{BL} = [(\tau\Sigma)^{-1} + P^T \Omega^{-1} P]^{-1} [(\tau\Sigma)^{-1} \pi + P^T \Omega^{-1} Q]
\]
其中 π 为均衡隐含收益，P/Q 为观点矩阵与观点收益，Ω 为观点不确定性，τ 为缩放因子。

**核心参数**：
- `risk_aversion`：风险厌恶系数（从均衡收益反推隐含 π）；
- `tau`：先验不确定性缩放因子；
- `lookback_days` / `cov_method`：协方差估计；
- `target_return` / `risk_free_rate`：优化目标参数。

**适用场景**：需要将研究观点（主观预期）与市场均衡结合的场景，输出比裸 MVO 更稳定的权重。

### 2.4 风险预算（risk_budget / RB）

**数学本质**：风险平价的推广——不要求各资产风险贡献相等，而是按指定的预算比例 \(b_i\) 分配风险贡献：\(RC_i / RC_{total} = b_i\)。

**核心参数**：
- `budget_mode`：预算来源模式；
- `risk_budgets`：各资产风险预算比例；
- `lookback_days` / `cov_method`：协方差估计；
- `risk_free_rate`：辅助参数。

**适用场景**：有明确风险分配意图的配置（如股债 30/70 风险预算）。

### 2.5 协方差-夏普优化（enhanced_risk_parity / CSO）

**数学本质**：对原纯风险平价策略的增强：在协方差框架的风险平价基础上叠加夏普比增强项，兼顾风险分散与收益质量。

**核心参数**：
- `lambda_sharpe`：夏普增强项权重系数（0 = 退化为纯风险平价）；
- `lookback_days` / `cov_method`：协方差估计。

**适用场景**：希望在风险平价稳健性上叠加收益信号倾斜的场景。

### 2.6 因子风险平价（factor_risk_parity）

**数学本质**：先对资产收益协方差做 PCA 分解，提取主成分作为风险因子，再在**因子空间**做风险平价（各因子等风险暴露），最后映射回资产权重。解决资产层面高相关导致的风险平价失真问题，实现真正多维度风险暴露均衡。

**实现结构**：因子提取逻辑封装为独立组件 `PcaFactorModel`（`app/allocation/factor_model.py`），策略层专注因子风险平价优化，模型可替换。

**核心参数**：
- `n_factors`：PCA 因子数量（默认 3；0 = 按累计解释方差自动确定）。注意：不建议让资产数少于因子数接近，边界情况因子分解接近资产本身；
- `explained_variance`：累计解释方差阈值（默认 0.85，仅 n_factors=0 时生效）；
- `include_specific_risk`：是否纳入特质性风险。

**适用场景**：资产间相关性高、希望在风险因子维度（而非资产维度）做分散的配置。

## 三、闭式/规则型详解

### 3.1 目标波动率预算（vol_scaled_budget / TVB）

**数学本质**：统一的编制规则模型，公式：
\[
w_i = b_i \times \frac{\sigma_{target}}{\sigma_{realized}}
\]
其中 \(b_i\) 为预算权重，通过 `budget_source` 切换不同预算来源（等权/逆波动等）。这是单资产权重上限约束（如 ZY_DOCUMENT_DEFAULT_MAX_WEIGHT=0.10）的合法适用对象。

**核心参数**：
- `budget_source`：预算来源切换；
- `target_vol`：目标年化波动率；
- `lookback_days`：已实现波动估计窗口。

### 3.2 等权轮动（etf_cycle_rotation）

**数学本质**：对选中的资产做 1/N 等权分配，选择逻辑完全交给上游选择器。最简单的编制规则，无优化计算。

**适用场景**：ETF 轮动类策略的分配层，重点在选品信号而非权重精细化。

### 3.3 信号加权（signal_weighted）

**数学本质**：把选择器输出的信号分数直接转化为分配权重（分数归一化），实现"信号即权重"的直通式配置。

**适用场景**：选择器分数本身具有权重含义的场景（如贴水率、夏普分数）。

### 3.4 手动配置（manual_allocation）

**数学本质**：用户直接指定各资产权重，不做任何优化计算。

**适用场景**：主观配置、基准组合、对照实验。

**典型用法**：行业固定比例组合（如“46 模型”股 40% 债 60%、“64 组合”股 60% 债 40%，命名规则见《业务术语表》）均通过本模型实例化，`parameters.manual_weights` 填目标比例且总和为 1；常作为优化类模型（风险平价、均值-方差等）回测对比的基准。

**回测约定**：本模型回测硬性要求至少一个预设调仓日（`parameters.manual_weight_adjustments`，预设日须在回测区间内且为有行情的交易日，否则报 400）——页面操作时在策略编辑页配置；Agent 对话内回测（run_backtest）对未预设调仓日的实例会自动以区间首个交易日为期初调仓日（权重取 manual_weights），等效期初建仓后全区间持有固定权重，正适合固定比例基准类模型。

### 3.5 类雪球Delta对冲（snowball_delta_hedge）

**定位**：策略库中唯一的负凸台策略。通过蒙特卡洛定价计算雪球期权的 Delta，动态调整 ETF 分布仓位，复制雪球结构收益。

**收益来源**：
- KO（敲出）：提前结束赚取票息；
- 未触发到期：赚取全部票息；
- KI（敲入）亏损：承担下跌损失（由 Delta 对冲部分抵消）。

**核心特征**：
- 单资产动态仓位，`delta_coef ∈ [-1, 1]`；
- 有状态合约生命周期管理：KO/KI/到期结算，每日循环执行"合约状态检查 → MC 定价 → Delta 数值微分 → 仓位系数 → 调仓"；
- 每日连续调仓；
- 内置蒙特卡洛定价引擎（定价种子 pricing_seed 固定保证可复现）与数值微分 Delta 计算；
- 支持单合约与多合约模式、单资产与多资产标的；
- 波动率估计：历史波动率（252 日年化）或 EWMA（λ=0.94）。

**技术要点**：该模型声明 `internal_leverage=True`，禁止 Pipeline 层再对其做杠杆缩放；Delta 对冲允许负权重。

## 四、通用注意事项

1. **参数分组语义**：`core` 组参数显著改变回测净值曲线（lookback_days、cov_method、lambda_sharpe 等），`advanced` 组仅影响数值精度或边界（min_weight/max_weight 等）；
2. **统一入口**：所有模型通过 `allocate(prices, **params)` 调用，Pipeline（`app/backtesting/composition_pipeline.py`）负责编排选择→分配→控制三层；
3. **波动率控制双轨**：分配模型输出权重后，波动率控制可走控制器层（只降不升的风险阀）或回测引擎层 vol_targeting（双向定标），二者语义不同，配置策略实例时需明确选择；
4. **权重边界约束**：单资产权重上限等约束仅适用于特定编制规则策略（如 vol_scaled_budget），不可泛化至 risk_parity、mean_variance 等通用优化策略。
