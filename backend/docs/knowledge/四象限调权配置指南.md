# 四象限调权配置指南

本文档是四象限权重模型（quadrant）的**前端配置操作指南**：配置入口、参数含义与默认值、信号判定口径、存储结构与常见问题。模型的金融原理与工程实现详见 repowiki《后端模块详解/组合管理/权重优化模型/四象限权重模型》页；后端实现位于 `app/portfolio/weight_models/quadrant.py`（`QuadrantWeightModel`），前端入口 `src/views/portfolio/PortfolioCreate.vue`。

## 一、模型定位

四象限模型是**组合层的动态调权方法**：不产生策略信号、不选择资产，而是根据一个**信号标的**的行情状态把市场划分为四个象限，在每个再平衡时点对组合内子策略按「**逆波动率基础权重 × 象限放大**」重新分配权重。

| | 低波（low_vol） | 高波（high_vol） |
|---|---|---|
| **上涨（up）** | up_low_vol | up_high_vol |
| **下跌（down）** | down_low_vol | down_high_vol |

## 二、配置入口与操作步骤

**组合管理 → 创建组合（或编辑组合）**：

1. 确认子策略均已**实盘发布**（策略模型列表），信号标的行情已导入资产库；
2. 来源类型选择 **组合模型（多策略）**；
3. 勾选 ≥2 个已发布的子策略（典型为覆盖四类行情风格的策略）；
4. 「权重构建方法」选择 **四象限调权**，页面展开四象限参数配置区（子策略初始权重自动按等权 1/N 填充，仅为起始占位，运行时由模型逐日动态覆盖，权重列显示「象限动态调权」标签）；
5. 选调仓模式（默认信号触发）、确认信号标的与放大倍数；
6. 为四个象限分别指定侧重策略（`signal_driven` / `monthly_quadrant` 模式必填）;
7. 如需产品层/母层定标，在对应区块启用并配置；
8. 保存后可在组合详情页回测验证，权重图应呈现象限切换日的再平衡跳变（T+2 生效）。

## 三、配置项详解

### 3.1 调仓模式（rebalance_mode）

| 模式 | 触发方式 | 权重逻辑 | 是否需要信号标的 |
|---|---|---|---|
| `signal_driven` 信号触发（默认） | 象限切换即触发再平衡，**T+2 个交易日生效**，非再平衡日权重自然漂移 | 逆波动率 × 象限 Boost | 是 |
| `monthly_quadrant` 月度象限 | 每月定期再平衡 | 逆波动率 × 象限 Boost 缩放 | 是 |
| `monthly_inv_vol` 月度逆波动率 | 每月定期再平衡 | 仅按波动率倒数分配，无象限 Boost | **否** |

### 3.2 信号标的（signal_code）

- 用于判定四象限的标的资产，默认 `600905.SH`；
- 仅 `signal_driven` / `monthly_quadrant` 模式需要；
- **前置条件**：信号标的的日线行情必须已导入资产库，否则回测时无法计算象限序列。

### 3.3 象限放大倍数（boost_factor）

- 当前象限侧重策略的权重放大倍数，范围 1–5，**默认 1.5**；
- 调权方式：侧重策略基础权重 × boost 后，其余策略等比缩减，合计仍归一化为 100%。

### 3.4 波动率窗口（vol_window）

- 逆波动率基础权重的计算窗口（交易日），范围 20–500，**默认 252**（约一年）；
- 子策略数据不足 60 日时该策略权重计 0；全部无效时退化为等权。

### 3.5 象限侧重策略映射（quadrant_strategy_map）

- 为四个象限分别指定应侧重加权的子策略（下拉只能从已选子策略中选择）：
  - **上涨 + 低波**：趋势上行且波动收缩，侧重方向性收益策略
  - **上涨 + 高波**：趋势上行但波动放大，侧重多资产分散策略
  - **下跌 + 低波**：趋势下行但波动收敛，侧重防御型策略
  - **下跌 + 高波**：趋势下行且波动放大，侧重对冲型策略
- `signal_driven` / `monthly_quadrant` 模式**必填**（后端强制校验，未配置直接报错）；
- 某象限未指定或指定的策略不在组合内时，该象限不做 Boost，仅用逆波动率基础权重；
- `monthly_inv_vol` 模式忽略此配置。

## 四、信号判定规则（后端固定口径）

以信号标的（如 600905.SH）的日线收盘价计算：

- **方向信号**：收盘价相对 60 日均线（SMA60）的偏离度，> +5% 判为 `up`，< −5% 判为 `down`；介于其间为盲区，**保持上期方向**；
- **波动信号**：HV20（20 日年化历史波动率）在过去 252 日的百分位排名，> 70% 判为 `high_vol`，< 30% 判为 `low_vol`；盲区**保持上期波动状态**；
- **象限**：方向与波动均非盲区时确定象限，否则保持上期象限；
- **起始日对齐**：组合起始日之前的信号不参与前向填充，因此组合首月无象限、不做 Boost（与原型口径一致）。

以上阈值（均线窗口 60、±5%、HV20、252 日、70%/30%）为后端固定口径，与原型 `signal_engine.py` 一致，前端暂不开放修改。

## 五、可叠加控制层

### 5.1 产品层配置（product_layer）

在策略组合之上叠加短债 + 现金，按目标波动率求解配比（月度调仓）：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用产品层 | 关 | 关闭时输出纯策略组合结果 |
| 目标波动率 | 2% | 年化 |
| 现金固定比例 | 15% | 其余部分在策略组合与短债间求解分配 |
| 波动率窗口 | 60 日 | 已实现波动率滚动窗口 |
| 短债资产 | CBA11321.CS | 短债专户净值代码 |
| 现金代理资产 | 511360.SH | 短融 ETF |

### 5.2 母层波动率定标（vol_target）

启用后组合收益按目标波动率逐日缩放：`leverage = clip(目标vol / 实现vol, 下界, 上界)`；可配置目标波动率、估计方法（滚动标准差 / EWMA）、短窗（默认 20）/长窗（默认 60）与杠杆上下界（默认 0.1–5.0）。

## 六、存储结构

保存后四象限参数写入组合的 `weight_model_params` 字段（MongoDB `portfolios` 集合），并**同步到关联的 `strategy_models` 文档**，保证日常监控与组合回测口径一致：

```json
{
  "weight_method": "quadrant",
  "weight_model_params": {
    "rebalance_mode": "signal_driven",
    "signal_code": "600905.SH",
    "boost_factor": 1.5,
    "vol_window": 252,
    "quadrant_strategy_map": {
      "up_low_vol": "<子策略模型ID>",
      "up_high_vol": "<子策略模型ID>",
      "down_low_vol": "<子策略模型ID>",
      "down_high_vol": "<子策略模型ID>"
    },
    "product_layer": {
      "enabled": true,
      "controller": "vol_target",
      "vol_target": 0.02,
      "cash_fixed": 0.15,
      "vol_window": 60,
      "annualize_factor": 252,
      "bond_code": "CBA11321.CS",
      "cash_code": "511360.SH"
    }
  }
}
```

> `product_layer` 始终随保存携带，以 `enabled` 字段控制启停；`monthly_inv_vol` 模式下不携带 `quadrant_strategy_map`。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 保存报错「必须配置 quadrant_strategy_map」 | `signal_driven` / `monthly_quadrant` 模式未给象限指定侧重策略，补齐映射 |
| 回测报错「需要提供信号标的价格序列」 | 信号标的代码错误或行情未导入，先在资产库/行情导入中补数据 |
| 组合首月权重为等权、无 Boost | 正常现象：组合起始日前信号不参与填充，首月无有效象限 |
| 监控与回测结果口径不一致 | 检查编辑保存是否正常同步 `strategy_models`（编辑端点会自动同步 product_layer 与象限参数） |
| 象限模式下权重列显示「象限动态调权」 | 正常：初始等权仅为占位，运行时由模型动态覆盖 |
