# 回测异常值与缺失值处理 - 修改说明

## 问题描述

当不同资产之间组合回测时，若数据缺少或不一致，会出现以下指标取值异常极端的情况：

- 回撤（最大回撤、当日回撤）
- 收益率（总收益率、年化收益率）
- 手续费
- 年化波动率
- 卡玛比率、夏普比率等

本次对异常值及缺失值的处理逻辑进行优化，并将修改内容与范围记录于此。

---

## 修改范围与内容

### 1. `app/backtesting/analytics.py`

**修改内容：**

- **绩效指标合理范围常量**  
  新增常量：总/年化收益率区间 `[-1, 10]`、年化波动率上限 `5.0`、最大回撤区间 `[-1, 0]`、夏普/卡玛等比率绝对值上限 `50`，用于在数据异常时限制指标范围。

- **`_clamp_performance_metric(value, name)`**  
  新增函数：按指标类型将数值限制在上述合理范围内，避免 inf/nan 或极端值进入后续计算与接口返回。

- **`from_results()` 中净值与收益率序列**  
  - 对 `total_value` 序列做清理：`astype(float)`、将 inf 替换为 nan、`ffill().bfill()` 填充缺失。  
  - 若有效长度不足 2 或全为 nan，直接返回全 0 的 `PerformanceSummary`。  
  - 收益率由 `pct_change()` 计算后，将 inf/-inf 替换为 nan 并 `dropna()`，再参与后续计算。

- **各指标计算后统一限制范围**  
  总收益率、年化收益率、年化波动率、最大回撤、夏普比率、卡玛比率、收益回撤比在计算完成后均通过 `_clamp_performance_metric` 限制在合理区间；总收益率计算时对 `start_value <= 0` 使用 `1e-12` 阈值避免除零。

- **`build_nav_and_drawdown_series()`**  
  - 对 `total_value` 做与上面一致的清理（inf/nan、ffill/bfill）。  
  - 首值无效或非正时，返回净值 1、回撤 0 的安全结果。  
  - 回撤序列计算后 `fillna(0).replace(inf,-inf, 0)`，并 `clip(lower=-1, upper=0)` 限制在 [-1, 0]。

**影响范围：** 所有使用 `PerformanceAnalyzer.from_results()` 及 `build_nav_and_drawdown_series()` 的回测结果（含普通回测、步进回测、混合动量等）。

---

### 2. `app/analysis/formulas/drawdown.py`

**修改内容：**

- **`_clean_prices_series(prices)`**  
  新增内部函数：将价格序列转为 float、inf/-inf 置为 nan、`ffill().bfill()`、剩余 nan 填 1.0，保证后续计算使用有限值。

- **`calculate_drawdown_series(prices)`**  
  - 先用 `_clean_prices_series` 清理价格。  
  - 首值非正或非有限时返回全 0 回撤序列。  
  - 回撤计算后 `fillna(0).replace(inf,-inf, 0)`，并 `clip(lower=-1, upper=0)` 限制在 [-1, 0]。

- **`calculate_max_drawdown(prices)`**  
  - 仍基于清理后的 `calculate_drawdown_series`。  
  - 对结果做 `math.isfinite` 检查，并将结果限制在 `[-1, 0]`。

**影响范围：** 所有使用上述回撤公式的模块（回测 API、资产指数 API、混合动量引擎等）。

---

### 3. `app/api/backtests.py`

**修改内容：**

- **绩效指标合理范围常量与 `_sanitize_performance_metrics(perf)`**  
  - 定义与 analytics 一致的合理区间常量。  
  - 新增 `_sanitize_performance_metrics(perf)`：对 dict 形式的绩效（total_return、annual_return、volatility、annual_volatility、max_drawdown、sharpe_ratio、calmar_ratio）做 nan/inf 清理并限制在上述范围内。

- **混合动量回测分支**  
  - 在构建 `BacktestResultOut` 前，对 `hm_result["performance"]` 调用 `_sanitize_performance_metrics`，再填入 total_return、annual_return、max_drawdown、calmar_ratio 等字段。  
  - 返回前对 `result_data` 调用 `_sanitize_dict_for_json(result_data)`，确保整包数据中的浮点数（含手续费、滑点等）无 inf/nan 且不超过已有极端值上限。

**影响范围：** 混合动量策略回测接口的返回结果；所有通过 `_sanitize_dict_for_json` 返回的回测结果中的浮点数（含手续费、收益率、回撤等）已统一做安全化处理。

---

### 4. `app/api/asset_index.py`

**修改内容：**

- **绩效指标合理范围常量**  
  与 analytics 对齐：收益率 [-1, 10]、波动率上限 5、最大回撤 [-1, 0]、比率绝对值上限 50。

- **`_compute_performance_from_nav(nav_history)`**  
  - 对 `nav_history` 中的 `nav` 做类型与有效性检查，非法或 inf/nan/负值按无效处理，构造列表后经 `pd.Series` 的 `replace(0, nan).ffill().bfill().fillna(1.0)` 填充缺失。  
  - 总收益率、年化收益率、年化波动率、最大回撤、夏普、卡玛计算后均限制在上述合理范围内。  
  - 收益率计算时使用 `years = max(days/252, 1e-6)` 避免除零；单日收益计算时对 `navs[i-1] > 1e-12` 做判断并丢弃非有限值。

**影响范围：** 大类资产指数相关接口中，由净值历史计算得到的绩效指标（回撤、收益率、波动率、卡玛等）。

---

## 未改动的相关逻辑

- **手续费/滑点在交易记录中的处理**  
  仍由现有的 `_sanitize_dict_for_json` 统一处理：递归遍历返回结构，对浮点数做 nan/inf 替换及绝对值上限裁剪（`_SANITIZE_FLOAT_ABS_MAX = 1e12`），因此手续费、滑点不会以 inf/nan 或超大数返回，无需在本次单独增加逻辑。

- **数据源层（DataFeed / MarketService）**  
  本次未修改行情获取与对齐逻辑；异常值处理集中在「计算与输出」层，避免在数据缺失或不一致时产生极端指标值。

---

## 合理范围汇总

| 指标             | 下限   | 上限   | 说明                         |
|------------------|--------|--------|------------------------------|
| 总收益率/年化收益率 | -100%   | 1000%  | 避免缺失/错误数据导致极端收益 |
| 年化波动率       | 0      | 500%   | 避免除零或异常波动           |
| 最大回撤         | -100%  | 0%     | 回撤为负值或 0               |
| 夏普/卡玛等比率  | -50    | 50     | 避免除零导致的极端比率       |
| 单笔手续费等浮点数 | -1e12  | 1e12   | 已有 `_sanitize_dict_for_json` 统一限制 |
