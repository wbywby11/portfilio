## 一、文档规定摘要

### 1. 指数权重计算日（第279行）

> 本指数按月度调仓，在每个指数权重计算日执行如下操作：  
> 1、基于动量模型在12个资产中选择**7个**进行配置；  
> 2、基于反转模型在12个资产中选择**1个**资产进行配置；  
> 3、基于目标波动控制算法求解组合权重。

→ **7 动量 + 1 反转**（7+1）

### 2. 有效资产集合 SET（第283-284行）

> 若资产 c 自资产计算基日（不含）至 t 日（含）满 **260 个净值计算日**，则资产 c 属于集合 SET。

→ `min_history_days = 260` ✓

### 3. 动量因子定义（第285-290行）

- 简单时序动量 **MOM**_t^c(n)
- 双均线动量 **MACD**_t^c(n)
- 收益正负差因子 **POSI**_t^c(n)
- 缩放动量因子 **SMOM**_t^c(n)  
- 综合打分：Score_t^c = Σ S_t^c(MOM,n) + Σ S_t^c(MACD,n) + Σ S_t^c(POSI,n) + Σ S_t^c(SMOM,n)

→ 实现：MOM/POSI/SMOM 窗口 22,65,260；MACD 26 ✓

### 4. 反转因子定义（第291-294行）

- 窗长 **10 天**的 SKEW  
- 窗长 **22 天**的 SKEW  
- Score_t^c = F(S_t.10^c) + F(S_t.22^c)，F(∙) 为排序函数：**从低到高**排序，最后一名取 1，倒数第二名取 2（即 SKEW 越小得分越高）

→ 实现：reversal_windows=[10,22]，ascending=True 排序 ✓

### 5. 动量资产选择（第295-297行）

> 将各个资产按照动量因子打分**从高到低**排序，选择总分**最高的 7 个**资产。  
> **如果出现打分相同的情况则其中打分最低且相同的资产均不入选。**

→ 严格取前 7 名（并列时按行序取前 7，不扩选）✓ 已按文档修正

### 6. 反转资产选择（第298-299行）

> 将各个资产按照反转因子打分从高到低排序，选择总分**最高的 1 个**资产。

→ **n_reversal = 1** ✓ 已按文档修正

### 7. 资产权重 / 风险预算（第300-306行）

- 若资产 c **仅被动量**选中：b_t^c = **1/8**
- 若资产 c **同时被动量和反转**选中：b_t^c = **2/8**
- 若资产 c **仅被反转**选中：b_t^c = **1/8**
- 若资产 c **未选中**：b_t^c = **0**

→ 实现：risk_budget_both=0.25，risk_budget_single=0.125 ✓

### 8. 波动率与目标波动率（第307-308、279行）

- 已实现波动率：过去 **22、65、130** 天年化波动率取**最大值**
- 指数目标波动 σ_target = **年化 5%**

→ 实现：vol_windows=[22,65,130]，target_vol=0.05 ✓

## 四、与策略联用：截取数据但不筛选资产

与 **RiskBudgetTargetVolStrategy** 等策略联用时，若回测区间较短或数据不足 260 天，选择层原先强制「满 260 天」会导致「没有资产满足最小历史数据要求(260天)」。  

**约定：** 采用「截取数据但不筛选资产」——当**全池最大可用天数** \< min_history_days 时，**有效资产**仅要求能计算因子的最小天数（约 26 天，满足 MACD/MOM_22/SKEW_22），不再按 260 天剔除资产；数据充足时仍按文档要求 260 天。

- **实现位置：** `app/selection/formula/advanced_momentum_factors.py` 中 `compute_advanced_momentum_scores`  
- **逻辑：** `effective_min = min_history_days if max_avail >= min_history_days else 26`，`valid = [c for c in prices.columns if 可用天数 >= effective_min]`  
- **效果：** 与风险预算+目标波动率策略联用时，短数据回测可正常选 7+1 并计算权重，不再因 260 天报错。
