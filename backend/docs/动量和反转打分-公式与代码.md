## 一、动量打分

### 1. 因子值计算（原始指标）

| 因子 | 公式 | 代码函数 | 默认窗口 |
|------|------|----------|----------|
| **MOM** | \( \text{MOM}_t^c(n) = \dfrac{TR_t^c}{TR_{t-n}^c} - 1 \) | `compute_simple_momentum` | 22, 65, 260 |
| **MACD** | \( \text{MACD} = (\text{EMA}_{12} - \text{EMA}_{26}) - \text{EMA}_9(\text{MACD线}) \) | `compute_macd_momentum` | 26（慢线） |
| **POSI** | \( \text{POSI}_t^c(n) = \dfrac{n^+ - n^-}{n} \)（窗口内正收益天数 − 负收益天数，再除以 n，范围 \([-1,1]\)） | `compute_posi_momentum` | 22, 65, 260 |
| **SMOM** | \( \text{SMOM} = \dfrac{\text{简单动量}}{\sigma_{\text{年化}}} \) | `compute_smom_momentum` | 22, 65, 260 |

- \( TR_t^c \)：资产 c 在 t 日的价格/净值（代码里用 `prices`）。
- 动量因子**数值越大越强**，后面按“从高到低”排序打分。

### 2. 动量打分的核心公式

对**每个**因子列（如 MOM_22, MOM_65, MACD_26, POSI_22, ...）：

1. **排序**：按因子值**从高到低**排序（越大排名越前）。
2. **名次**：\( \text{Rank}_\text{col} = \text{rank}(\text{因子列}, \text{ascending}=\text{False}, \text{method}=\text{min}) \)
3. **单因子得分**：\( S_\text{col} = n - \text{Rank}_\text{col} + 1 \)（n = 有效资产数量）
4. **动量总分**：\( \text{TotalMomentumScore} = \sum_{\text{所有因子列}} S_\text{col} \)

即：**每个因子先按“谁大谁好”排名，再变成 1～n 的得分，最后把所有因子的得分加总。**

### 3. 动量打分代码（核心片段）

```python
# 对每个因子列：降序排名，再转为得分
for col in mom_df.columns:
    mom_df[f"Rank_{col}"] = mom_df[col].rank(ascending=False, method="min")
    mom_df[f"Score_{col}"] = n - mom_df[f"Rank_{col}"] + 1
# 总分 = 所有 Score_* 列之和
sc = [f"Score_{x}" for x in mom_df.columns if not x.startswith(("Rank_", "Score_"))]
mom_df["TotalMomentumScore"] = mom_df[sc].sum(axis=1)
```

文件位置：约第 104–109 行。

## 二、反转打分

### 1. 因子值计算（原始指标）

| 因子 | 公式 | 代码函数 | 默认窗口 |
|------|------|----------|----------|
| **SKEW** | \( \text{SKEW}_t^c(n) = \text{偏度}(\text{窗口内日收益率序列}) \) | `compute_skew_factor` | 10, 22 |

- 偏度：`pandas.Series.skew()`，即收益率分布的三阶矩偏度。
- 反转逻辑：**SKEW 越小（越负）越“反转”**，后面按“从低到高”排序打分。

### 2. 反转打分的核心公式

对**每个**SKEW 列（如 SKEW_10, SKEW_22）：

1. **排序**：按 SKEW 值**从低到高**排序（越小排名越前）。
2. **名次**：\( \text{Rank}_\text{col} = \text{rank}(\text{SKEW列}, \text{ascending}=\text{True}, \text{method}=\text{min}) \)
3. **单因子得分**：\( S_\text{col} = n - \text{Rank}_\text{col} + 1 \)
4. **反转总分**：\( \text{TotalReversalScore} = \sum_{\text{所有 SKEW 列}} S_\text{col} \)

即：**每个 SKEW 先按“谁小谁好”排名，再变成 1～n 的得分，最后把所有 SKEW 的得分加总。**

### 3. 反转打分代码（核心片段）

```python
# 对每个 SKEW 列：升序排名（SKEW 小排前面），再转为得分
for col in rev_df.columns:
    rev_df[f"Rank_{col}"] = rev_df[col].rank(ascending=True, method="min")
    rev_df[f"Score_{col}"] = n - rev_df[f"Rank_{col}"] + 1
# 总分 = 所有 Score_* 列之和
rc = [f"Score_{x}" for x in rev_df.columns if not x.startswith(("Rank_", "Score_"))]
rev_df["TotalReversalScore"] = rev_df[rc].sum(axis=1)
```

文件位置：约第 119–124 行。

## 三、汇总对照

| 项目 | 动量 | 反转 |
|------|------|------|
| 因子 | MOM, MACD, POSI, SMOM | SKEW |
| 窗口 | MOM/POSI/SMOM: 22,65,260；MACD: 26 | 10, 22 |
| 排序方向 | 因子值**从高到低**（越大越好） | SKEW **从低到高**（越小越好） |
| 单因子得分 | \( S = n - \text{Rank} + 1 \) | \( S = n - \text{Rank} + 1 \) |
| 总分 | TotalMomentumScore = Σ 各因子 Score | TotalReversalScore = Σ 各 SKEW Score |
| 选择 | TotalMomentumScore 前 7 名 | TotalReversalScore 前 1 名 |

同一套“先按因子排序 → 转成 1～n 得分 → 再对多列得分加总”的逻辑，动量用降序、反转用升序，对应编制规则中的排序函数 F(·)。
