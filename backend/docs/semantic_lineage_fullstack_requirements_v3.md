## 一、战略愿景与目标

### 1.1 愿景

构建**全链路语义感知、端到端血缘可追溯、统计画像智能洞察**的金融资管数据平台，实现：

- **数据可信**: 任何数据点均可追溯至原始来源，知晓"这个数据从哪来、怎么算的、什么时候更新的"
- **语义统一**: 前后端、人机交互使用同一套业务语义，消除"字段名与业务含义脱节"的鸿沟
- **智能增强**: Agent具备数据语义感知能力，能解释字段含义、推荐查询路径、评估数据质量
- **统计洞察**: Agent具备宏观数据体感，能理解单表分布、域级趋势、跨域共振，从"查数据"升级为"读数据"
- **影响可控**: 上游数据变更时，能精准评估下游影响范围，降低"改了A导致B出错"的风险

### 1.2 目标能力矩阵

| 能力维度 | 现状 | 目标 | 度量指标 |
|---------|------|------|----------|
| 语义层覆盖 | 概念层(9域82表) | 概念层+逻辑层+物理层+质量层+统计层 | 字段级语义覆盖率100% |
| 血缘追踪 | 无 | 端到端(上游API→存储→查询→消费) | 链路完整率>95% |
| 血缘粒度 | 无 | 字段级 | 字段级血缘占比>80% |
| 前端语义 | 无 | Schema语义标注+字段Tooltip+统计摘要 | 关键字段覆盖率100% |
| Agent语义 | 离散式(schema+示例查询) | 统一语义服务层+统计画像感知 | 查询意图理解准确率>90% |
| 数据质量 | 无 | 质量徽章+评分 | 质量评分覆盖率100% |
| 统计画像 | 无 | 单表/域级/跨域三层统计摘要 | 核心表覆盖率100%，域级画像9域全覆盖 |

### 2.3 现有链路分析

**前端链路**: `zyDataDomain.js` → `zy_data.py` API → `GenericQueryEngine` → MongoDB
- 问题: API返回纯数据，无任何语义元数据
- 问题: 前端不知道字段的业务含义

**Agent链路**: `data_query_tool.py` → `DataContext` → schema/示例查询
- 问题: 语义感知离散（schema和示例查询分离）
- 问题: 无统一语义服务层
- 问题: Agent无法解释字段含义
- 问题: Agent无宏观数据体感，只能"查数据"不能"读数据"

**数据接入链路**: `DataHubService.import_from_upstream()` → 上游API → MongoDB
- 问题: 无血缘记录，不知道数据从哪来
- 问题: 无质量评估
- 问题: 无统计画像生成

## 三、差距分析矩阵

### 3.1 语义层差距

| 层级 | 现状 | 目标 | 差距描述 |
|------|------|------|----------|
| **概念层** | ✅ `DOMAIN_METADATA`(9域82表) | 扩展为语义实体定义 | 缺语义实体、跨域关联链、术语表 |
| **逻辑层** | ❌ 无 | 逻辑表/字段定义 | 缺逻辑模型、字段级语义画像 |
| **物理层** | ⚠️ 动态推断schema | 物理映射+质量画像 | 缺静态物理映射、缺质量评分 |
| **质量层** | ❌ 无 | 质量画像+评分 | 完全缺失 |
| **统计层** | ❌ 无 | 单表/域级/跨域统计画像 | 完全缺失，Agent无宏观体感 |

### 3.2 统计画像差距

| 画像类型 | 现状 | 目标 | 差距描述 |
|---------|------|------|----------|

| **域级全局画像** | ❌ 无 | 每个数据域的宏观聚合摘要 | Agent无法感知域级资金端/资产端体感 |
| **跨域联动画像** | ❌ 无 | 跨域因果关联的共振摘要 | Agent无法理解资产负债联动、流动性传染 |

### 3.3 血缘追踪差距

| 追踪维度 | 现状 | 目标 | 差距描述 |

| **字段级血缘** | ❌ 无 | 字段级影响分析 | 完全缺失 |

### 4.3 L5: 统计语义画像层 (Statistical Semantic Profile)

#### 4.3.1 设计目标

**回答核心问题**: "这张表/这个域的数据长什么样？"

统计语义画像层将底层的纯数学/统计算子得出的冷冰冰的JSON，转化为大模型能瞬间理解的**"自然语言摘要(NL Digest)"**。它让Agent具备"宏观数据体感"——不是只能查某条记录，而是能感知整张表、整个域、甚至跨域的数据脉搏。

#### 4.3.2 三层统计画像架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    L5: 统计语义画像层 (三层架构)                              │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │  L5.1: 单表统计画像 (Table-Level Profile)                            │    │
│  │  ─────────────────────────────────────────────────────────────────  │    │
│  │  对象: 单张数据表 (如 dwd_mkt_bond_yield)                            │    │
│  │  频率: 日终T+1批处理                                                 │    │
│  │  摘要维度: 物理基础 + 截面分布 + 时序趋势 + 异常极值                  │    │
│  │  输出: 自然语言摘要文本 → 向量化入库 → Agent检索                      │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │  L5.2: 数据域全局画像 (Domain-Level Profile)                         │    │
│  │  ─────────────────────────────────────────────────────────────────  │    │
│  │  对象: 整个数据域下所有表 (如 客户与负债域 CUS)                       │    │
│  │  频率: 日终T+1批处理                                                 │    │
│  │  摘要维度: 域边界 + 宏观分布 + 宏观趋势 + 系统性异常                  │    │
│  │  输出: 自然语言摘要文本 → 向量化入库 → Agent宏观锚点                  │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │  L5.3: 跨域联动画像 (Cross-Domain Profile)                           │    │
│  │  ─────────────────────────────────────────────────────────────────  │    │
│  │  对象: 多个数据域的关联 (如 PTL+MKT+CUS 资产负债共振)                 │    │
│  │  频率: 日终T+1批处理 + 实时触发(异常检测)                             │    │
│  │  摘要维度: 场景定义 + 跨域结构 + 共振趋势 + 极端脱钩                  │    │
│  │  输出: 自然语言摘要文本 → 向量化入库 → Agent全局视野                  │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 4.3.3 L5.1: 单表统计画像

##### 4.3.3.1 画像内容

单表统计画像针对单张数据表，生成包含以下四个维度的自然语言摘要：

| 维度 | 说明 | 算子示例 | 输出示例 |
|------|------|----------|----------|
| **物理基础特征** | 表的基本信息 | 记录数、字段数、最新更新日期、数据粒度 | "包含3,500只活跃信用债的每日收益率数据" |
| **截面分布特征** | 当前截面的数据分布 | 分类占比、评级分布、行业集中度、数值分位 | "AAA评级占比75%，城投和金融为主" |
| **时序趋势特征** | 近期的变化趋势 | 时间序列平滑、趋势方向、波动率、拐点检测 | "短端收益率平滑下行，长端高波动震荡" |
| **异常与极值特征** | 尾部异常和极端值 | 3Sigma检测、Z-Score、离群点、背离检测 | "房地产15只债券出现背离型下跌，利差走阔25BP" |

##### 4.3.3.2 摘要生成模板

```
【表名/作用】本数据域为{表中文名}，当前业务日期至{BIZ_DATE}，包含{记录数}条记录。

【物理基础特征】数据粒度为{粒度}，覆盖{覆盖范围}，最新更新时间为{更新时间}。

【分布特征】当前截面{分类字段}极度集中于{TOP1分类}（占比{TOP1占比}%），{分类字段2}分布以{TOP2分类}和{TOP3分类}为主。
{数值字段}的中位数为{中位数}，75%分位为{P75}，25%分位为{P25}。

【趋势特征】近{时间窗口}个{时间单位}，{字段1}呈{趋势方向1}趋势，{字段2}呈现{趋势特征2}。
整体波动率为{波动率}，较上期{变化方向}{变化幅度}。

【异常与微观特征】检测到{异常类型}：{异常描述}。

class TableStatisticalProfiler:
    """单表统计画像生成器"""
    
    async def generate_profile(self, collection_name: str, biz_date: str) -> StatisticalProfile:
        """生成单表统计画像"""
        
        # 1. 物理基础特征
        physical = await self._extract_physical_features(collection_name, biz_date)
        
        # 2. 截面分布特征
        distribution = await self._extract_distribution_features(collection_name, biz_date)
        
        # 3. 时序趋势特征
        trend = await self._extract_trend_features(collection_name, biz_date, window=30)
        
        # 4. 异常与极值特征
        anomaly = await self._extract_anomaly_features(collection_name, biz_date)
        
        # 5. 生成自然语言摘要
        nl_digest = self._generate_nl_digest(physical, distribution, trend, anomaly)
        
        # 6. 生成向量嵌入
        embedding = await self._generate_embedding(nl_digest)
        
        return StatisticalProfile(
            collection_name=collection_name,
            biz_date=biz_date,
            physical_features=physical,
            distribution_features=distribution,
            trend_features=trend,
            anomaly_features=anomaly,
            nl_digest=nl_digest,
            embedding=embedding,
        )
    
    async def _extract_physical_features(self, collection: str, biz_date: str) -> dict:
        """提取物理基础特征"""
        return {
            "record_count": await self._count_records(collection, biz_date),
            "field_count": await self._count_fields(collection),
            "latest_update_time": await self._get_latest_update(collection),
            "data_granularity": self._infer_granularity(collection),
            "coverage_scope": self._infer_coverage(collection),
        }
    
    async def _extract_distribution_features(self, collection: str, biz_date: str) -> dict:
        """提取截面分布特征"""
        # 分类字段占比
        categorical = await self._analyze_categorical_distribution(collection, biz_date)
        # 数值字段分位
        numerical = await self._analyze_numerical_distribution(collection, biz_date)
        # 集中度指标
        concentration = await self._analyze_concentration(collection, biz_date)
        
        return {
            "categorical_distribution": categorical,
            "numerical_distribution": numerical,
            "concentration": concentration,
        }
    
    async def _extract_trend_features(self, collection: str, biz_date: str, window: int) -> dict:
        """提取时序趋势特征"""
        return {
            "trend_direction": await self._detect_trend(collection, biz_date, window),
            "volatility": await self._calculate_volatility(collection, biz_date, window),
            "momentum": await self._calculate_momentum(collection, biz_date, window),
            "inflection_points": await self._detect_inflection_points(collection, biz_date, window),
        }
    
    async def _extract_anomaly_features(self, collection: str, biz_date: str) -> dict:
        """提取异常与极值特征"""
        return {
            "outliers_3sigma": await self._detect_3sigma_outliers(collection, biz_date),
            "tail_events": await self._detect_tail_events(collection, biz_date),
            "divergence_patterns": await self._detect_divergence(collection, biz_date),
            "zscore_extremes": await self._detect_zscore_extremes(collection, biz_date),
        }
```

#### 4.3.9 L5 意义解读

> **为什么需要L5？**
> 
> L1-L4解决了"这个字段是什么、跟谁有关、有什么特性、质量如何"的问题，但没有回答"这张表的数据长什么样"。在金融资管场景中，Agent不仅需要知道字段含义，更需要感知数据的宏观脉搏——"当前市场信用债收益率整体在下行""负债端资金在避险""资产负债出现共振风险"。L5统计语义画像层将冰冷的统计数据转化为大模型能理解的"自然语言摘要"，让Agent从"查数据"升级为"读数据"。
> 
> **核心价值**:
> - **宏观体感**: Agent具备"资金端"和"资产端"的宏观感知能力
> - **自然语言理解**: 用户用"最近市场怎么样"提问，Agent能引用画像回答
> - **洞察发现**: 自动发现数据中的异常和趋势，无需人工巡检
> - **投研赋能**: 为分析师提供数据洞察，加速报告生成
> - **风险预警**: 跨域联动画像提前发现资产负债共振等系统性风险

### 5.2 核心设计原则 (V3更新)

| 原则 | 说明 | 具体措施 |
|------|------|----------|
| **保护现有投资** | 不替换`DOMAIN_METADATA`，而是扩展 | 语义层作为独立集合，通过`collection_name`关联 |
| **技术栈一致** | 继续使用MongoDB | 图模型用节点+边集合存储，不引入Neo4j |
| **增量增强** | Agent架构不变 | `SemanticLayerClient`作为`DataContext`的依赖注入 |
| **零侵入采集** | 血缘采集不阻塞主流程 | 异步内存队列+批量写入，目标<5ms/调用 |
| **结构化节点ID** | 自描述、可前缀查询 | 格式: `{type}:{namespace}:{name}:{version}` |
| **统计画像自动化** | 日终T+1自动生成 | 后台"总结Agent"调用底层算子，无需人工干预 |
| **自然语言输出** | 统计数据→NL摘要→向量嵌入 | 大模型可理解的语义格式，支持语义检索 |

#### 6.1.4 意义解读

> **为什么语义层是"大脑"？**
> 
> 没有语义层，系统只是"存储和搬运数据"——知道AST_CD存在，但不知道它是"证券代码"。语义层赋予数据"业务含义"，使系统从"数据搬运工"升级为"数据理解者"。V3新增的L5统计语义层更进一步，让系统从"理解字段"升级为"感知数据脉搏"。
> 
> **核心价值**:

#### 6.5.4 意义解读

>

> 
> **核心价值**:
> - **来源可追溯**: 知道每条数据来自哪个上游系统、哪个API、什么时间
> - **质量可评估**: 导入时即评估数据质量，早发现早处理
> - **批次可追踪**: 问题数据可追溯到具体导入批次
> - **变更可感知**: 发现数据异常变化，及时告警
> - **自动画像**: 数据导入后自动生成统计画像，无需人工干预
> - **宏观体感**: 域级和跨域画像为Agent提供持续的宏观数据脉搏

class DataContext:
    def __init__(self, conversation_id: str, semantic_client: Optional[SemanticLayerClient] = None):
        self.conversation_id = conversation_id
        self._store: dict[str, dict] = {}
        self._tool_history: list[dict] = []
        self._step_counter: int = 0
        self._last_access: float = time.time()
        self._created_at: float = time.time()
        self._semantic_client = semantic_client
        self._lineage_session: Optional[str] = None
    
    async def get_semantic_schema(self, collection: str) -> dict:
        """获取语义增强的Schema"""
        if self._semantic_client:
            return await self._semantic_client.get_schema(collection)
        return {}
    
    async def explain_field(self, collection: str, field: str) -> str:
        """解释字段含义"""
        if self._semantic_client:
            profile = await self._semantic_client.get_field_profile(collection, field)
            return f"{profile['display_name']}: {profile['business_definition']}"
        return ""
    
    async def get_statistical_profile(self, target: str, profile_type: str = "table") -> Optional[dict]:
        """获取统计画像，用于宏观体感"""
        if self._semantic_client:
            return await self._semantic_client.get_statistical_profile(target, profile_type)
        return None
    
    async def search_statistical(self, question: str) -> list[dict]:
        """语义检索统计画像"""
        if self._semantic_client:
            return await self._semantic_client.search_statistical(question)
        return []
    
    def store(self, data, tool_name, params, key=None):
        # 现有逻辑...

        if self._lineage_session:
            lineage_tracker.record_tool_execution(

### 10.2 Agent Prompt模板 (V3新增统计画像)

```python
# Agent Prompt中注入统计画像上下文

STATISTICAL_PROFILE_PROMPT_TEMPLATE = """
你是金融资管数据平台的智能助手。在回答用户问题前，请参考以下统计画像信息：

{statistical_profiles}

请基于以上画像信息，回答用户的问题。如果画像信息与用户问题相关，请引用具体数据支撑你的回答。
如果画像信息不足以回答问题，请明确告知用户，并建议查询具体数据。

用户问题: {user_question}
"""

async def build_agent_prompt_with_statistical(
    data_context: DataContext,
    user_question: str
) -> str:
    """构建带统计画像感知的Agent Prompt"""
    
    # 1. 语义检索相关统计画像
    related_profiles = await data_context.search_statistical(user_question)
    
    # 2. 构建画像上下文
    profile_contexts = []
    for profile in related_profiles[:3]:  # 最多引用3个画像
        profile_contexts.append(profile["nl_digest"])
    
    # 3. 构建完整Prompt
    return STATISTICAL_PROFILE_PROMPT_TEMPLATE.format(
        statistical_profiles="\n\n".join(profile_contexts),
        user_question=user_question
    )
```
