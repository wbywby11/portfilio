## 2. 差异来源逐项说明

### 2.1 漂移口径（主要来源，系统性、有界）

旧路径权重演化：`w_series[i] = drift(w_series[i-1], ret[i-1])`，
生效权重 `eff_weights = w_series.shift(exec_delay)`。
叠加后 **t 日收益实际使用 t-2 日收盘的市值权重**；
而真实市值动态下 t 日收益应使用 t-1 日收盘权重。
即旧路径的漂移相对真实市值动态**滞后一天**，每次再平衡后重新对齐，
误差在再平衡间隔内累积。

新路径在统一引擎内按持仓数量逐日撮合，权重漂移为**严格市值口径**。

量级：与「子策略收益差异 × 权重偏离」同阶。合成数据实测 1.8e-3 ~ 3.2e-3（420 天），
GMSI2 真实数据 2.8e-3（2614 天），均远小于策略本身的不确定性。

**处置**：新路径口径为正确口径，P3 切换后固化新基线；旧路径不再修正。

### 2.2 期初口径窗口

旧路径 `eff_weights.shift(delay).fillna(初始权重)`：回测前 delay 日按配置权重计收益；
新路径首日收盘按期初权重（再平衡首日 = 权重模型目标权重）建仓、次日起承接收益。
两者仅影响最初 1~2 个交易日，比对时以锚点归一化消除。

### 2.3 母层波动率定标预热

旧路径直接对 `raw_ret = Σ eff_w × sub_ret` 滚动计算波动率；
新路径经引擎 return-level 定标，需 ≥10 个已实现收益起步（历史不足时 leverage=1.0）。
预热窗口（约前 10 日）内两者杠杆序列口径略异，之后收敛到同一公式
（dual-window：`(vol_short + vol_long)/2`，`leverage = clip(target/vol_est, 0.1, 5.0)`，
按 `leverage.shift(1)` 生效）。GMSI2 比对锚点取预热期后，剩余差异全部归入 2.1。

### 2.4 组合层成本建模

旧路径恒为零成本（权重代数复合，无撮合）。
新路径成本经 `commission_rate` / `slippage` 显式建模，默认 0 → 与旧路径可比；
P3 切换后调用方可按需开启真实成本（能力增强，不是差异）。

## 3. 事件驱动语义核对（四象限）

- 信号值变化日经 `ExecutionSchedule.event_dates` 声明，T+2 生效、生效日前一交易日收盘成交，
  与旧路径 `rebalance_signal` + `shift(exec_delay)` 逐日对齐（解析基准逐位验证）；
- 首日事件由 `config.initial_weights` 期初建仓承载（取同一权重模型首日目标权重），
  不重复声明，与旧路径「首日事件只产生一份生效权重」一致；
- `weight_drift=False`（月内不漂移）经适配器每日结算钩子无成本复位实现，
  收益口径与旧路径周期内权重恒定逐位一致。
