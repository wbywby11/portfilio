# 动量因子得分实现：图片参考代码 vs portfilio-end 对照与差异解析

## 一、对照总览

| 因子 | 图片中的实现要点 | portfilio-end 实现要点 | 是否一致 |
|------|------------------|------------------------|----------|
| **MOM** | f_mom(price,win) 后 mom>th→1 否则 0 | (TR_t/TR_{t-n})-1，S=1 若 F>-0.02 | ✅ 一致 |
| **MACD** | 价格双均线差：short SMA - long SMA | n 期动量/250 期动量（收益率比值） | ❌ 定义不同 |
| **POSI** | (正收益和) - \|负收益和\| = 区间总收益 | rpos + rneg（正收益和+负收益和） | ✅ 等价 |
| **SMOM** | mom × (vol_target/vol)，vol=rolling(win).std() 年化 | MOM × (4.5%/σ)，σ=60 日、相对 n 日均值方差年化 | ⚠️ 波动率定义不同 |
| **信号** | F > th → 1，否则 0 | F > -0.02 → 1，否则 0 | ✅ 一致 |

## 二、分因子实现逻辑解析与差异

### 1. MOM（简单时序动量）

**图片逻辑（f_mom_signal）：**
- 先算 `mom = f_mom(price, win)`（未在图中给出，通常即区间收益 (TR_t/TR_{t-n})-1）。
- 二值信号：`mom > th` 则为 1，否则 0。

**图片参考代码（根据描述还原）：**
```python
def f_mom_signal(price, win, th):
    mom = f_mom(price, win)   # 图中未给出 f_mom，通常为 (TR_t/TR_{t-n})-1
    mom_signal = mom.copy()
    mom_signal[mom > th] = 1
    mom_signal[mom <= th] = 0
    return mom_signal
```

**portfilio-end 逻辑：**
- `compute_simple_momentum(prices, window)`：  
  `(prices.iloc[-1] / prices.iloc[-window-1]) - 1`，即 **MOMc(n) = (TR_t/TR_{t-n}) - 1**。
- `trading_signal(factor_value, threshold=-0.02)`：  
  `1 if factor_value > threshold else 0`。

**portfilio-end 对应代码**（`app/selection/formula/advanced_momentum_factors.py`）：
```python
def compute_simple_momentum(prices: pd.Series, window: int) -> float:
    """简单时序动量 MOMc(n) = (TR_t / TR_{t-n}) - 1"""
    if len(prices) < window + 1:
        return 0.0
    return float((prices.iloc[-1] / prices.iloc[-window - 1]) - 1)

def trading_signal(factor_value: float, threshold: float = SIGNAL_THRESHOLD) -> int:
    """单动量因子交易信号 S_c(F,n)：F > threshold 则为 1，否则 0"""
    return 1 if factor_value > threshold else 0
# SIGNAL_THRESHOLD = -0.02
```

**结论：** 公式与信号规则一致；本端固定阈值 -0.02，与编制规则一致。

### 2. MACD（双均线/相对动量）—— 定义不同

**图片逻辑（f_macd / f_macd_signal）：**
- **因子定义**：`f_macd(price, win_short, win_long)`  
  - `k_short = price.rolling(win_short).mean()`  
  - `k_long = price.rolling(win_long).mean()`  
  - `macd = k_short - k_long`  
  即 **价格的短长期简单均线之差**（类似经典 MACD 的线差，但用 SMA）。
- 信号：macd > th → 1，否则 0。

**图片参考代码（根据描述还原）：**
```python
def f_macd(price, win_short, win_long):
    k_short = price.rolling(win_short).mean()
    k_long = price.rolling(win_long).mean()
    macd = k_short - k_long
    return macd

def f_macd_signal(price, win_short, win_long, th):
    macd = f_macd(price, win_short, win_long)
    macd_signal = macd.copy()
    macd_signal[macd > th] = 1
    macd_signal[macd <= th] = 0
    return macd_signal
```

**portfilio-end 逻辑：**
- **因子定义**：`compute_macd_momentum_new(prices, window, long_window=250)`  
  - `mom_n = (TR_t/TR_{t-n}) - 1`  
  - `mom_250 = (TR_t/TR_{t-250}) - 1`  
  - `MACDc(n) = mom_n / mom_250`  
  即 **n 期动量 ÷ 250 期动量**（收益率比值，相对长期动量的强弱）。

**portfilio-end 对应代码**（`app/selection/formula/advanced_momentum_factors.py`）：
```python
def compute_macd_momentum_new(
    prices: pd.Series,
    window: int,
    long_window: int = 250,
) -> float:
    """双均线动量（新定义）MACDc(n) = ((TR_t/TR_{t-n}) - 1) / ((TR_t/TR_{t-250}) - 1)"""
    if len(prices) < long_window + 1 or window < 1:
        return 0.0
    mom_n = (prices.iloc[-1] / prices.iloc[-window - 1]) - 1
    mom_250 = (prices.iloc[-1] / prices.iloc[-long_window - 1]) - 1
    if abs(mom_250) < 1e-12:
        return 0.0
    return float(mom_n / mom_250)
```

**差异要点：**
- 图片：**价格空间**上的双均线差（SMA 差）。
- 本端：**收益率空间**上的“短期动量/长期动量”比值，与编制规则一致。
- 二者数学形式与含义均不同，**不可视为同一因子**。本端按编制规则实现，不按图片的 SMA 差实现。

### 3. POSI（收益正负差因子）—— 等价

**图片逻辑（f_posi）：**
- `rtn = price.pct_change()`
- `rtn_pos = rtn.mask(rtn < 0, 0)`（只保留正收益）
- `rtn_neg = rtn.mask(rtn > 0, 0)`（只保留负收益，值仍为负）
- `posi = rtn_pos.rolling(win).sum() - rtn_neg.rolling(win).sum().abs()`  
  即 **(正收益之和) - |负收益之和|**。  
  因为 sum(负) 为负，减其绝对值等于加 sum(负)，所以 **posi = 正收益和 + 负收益和 = 区间总收益**。

**图片参考代码（根据描述还原）：**
```python
def f_posi(price, win):
    rtn = price.pct_change()
    rtn_pos = rtn.mask(rtn < 0, 0)
    rtn_neg = rtn.mask(rtn > 0, 0)
    posi = rtn_pos.rolling(win).sum() - rtn_neg.rolling(win).sum().abs()
    return posi

def f_posi_signal(price, win, th):
    posi = f_posi(price, win)
    posi_signal = posi.copy()
    posi_signal[posi > th] = 1
    posi_signal[posi <= th] = 0
    return posi_signal
```

**portfilio-end 逻辑：**
- `compute_posi_momentum_new(prices, window)`：  
  - 过去 n 日收益：`returns = _daily_returns(prices).iloc[-window:]`  
  - `rpos = returns[returns > 0].sum()`  
  - `rneg = returns[returns < 0].sum()`（为负或 0）  
  - `POSIc(n) = rpos + rneg`  
  即 **正收益之和 + 负收益之和**，等于区间总收益。

**portfilio-end 对应代码**（`app/selection/formula/advanced_momentum_factors.py`）：
```python
def _daily_returns(prices: pd.Series) -> pd.Series:
    """日收益率 r_t = (TR_t / TR_{t-1}) - 1"""
    return prices.pct_change().dropna()

def compute_posi_momentum_new(prices: pd.Series, window: int) -> float:
    """收益正负差因子（新定义）POSIc(n) = rpos^c(n) + rneg^c(n)."""
    if len(prices) < window + 1:
        return 0.0
    returns = _daily_returns(prices).iloc[-window:]
    rpos = returns[returns > 0].sum()
    rneg = returns[returns < 0].sum()
    # ... 转为 float 处理 ...
    return float(rpos + rneg)
```

**结论：** 数学上等价，均为区间总收益；仅写法不同（一个用“正和 − |负和|”，一个用“正和 + 负和”）。

### 4. SMOM（缩放动量）—— 思路一致，波动率定义不同

**图片逻辑（f_smom）：**
- `vol = price.pct_change().rolling(win).std() * np.sqrt(n_annual)`  
  → **win 期收益的滚动标准差再年化**（n_annual=252）。
- `mom = f_mom(price, win)`
- `smom = mom * (vol_target / (vol * np.sqrt(n_annual)))`  
  （若 vol 已年化，则实际多为 `smom = mom * (vol_target / vol)`。）  
  即 **MOM 按（目标波动率/实际波动率）缩放**。

**图片参考代码（根据描述还原）：**
```python
def f_smom(price, win, vol_target, n_annual=252):
    vol = price.pct_change().rolling(win).std() * np.sqrt(n_annual)
    mom = f_mom(price, win)
    smom = mom * (vol_target / (vol * np.sqrt(n_annual)))
    return smom

def f_smom_signal(price, win, vol_target, th, n_annual=252):
    smom = f_smom(price, win, vol_target, n_annual)
    smom_signal = smom.copy()
    smom_signal[smom > th] = 1
    smom_signal[smom <= th] = 0
    return smom_signal
```

**portfilio-end 逻辑：**
- **波动率** `compute_volatility_sigma_n(prices, n, vol_window=60)`：  
  - 取最近 **60 日**收益，`mean_n` 为最近 **n 日**收益均值。  
  - `σ_n^c = sqrt(250/60 * Σ_{i=t-60+1}^{t} (r_i - mean_n)^2)`  
  → **60 日窗口、中心化为 n 日均值的方差**，再乘以 250/60 年化。
- **SMOM**：`compute_smom_momentum_new`：  
  - `smom = MOMc(n) * (4.5% / σ_n^c)`  
  即 **MOM 按（目标波动率/σ）缩放**，与图片形式一致。

**portfilio-end 对应代码**（`app/selection/formula/advanced_momentum_factors.py`）：
```python
VOLATILITY_WINDOW = 60
VOL_ANNUALIZATION = 250 / 60
TARGET_VOLATILITY = 0.045

def compute_volatility_sigma_n(
    prices: pd.Series,
    n: int,
    vol_window: int = VOLATILITY_WINDOW,
) -> float:
    """σ_n^c = sqrt(250/60 * Σ (r_i - mean_n)^2)，60 日窗口，mean_n 为过去 n 日收益均值"""
    returns = _daily_returns(prices)
    need = max(vol_window, n)
    if len(returns) < need:
        return 0.0
    r_last = returns.iloc[-vol_window:]
    mean_n = returns.iloc[-n:].mean()
    deviations = r_last - mean_n
    sum_sq = (deviations ** 2).sum()
    sigma = np.sqrt(VOL_ANNUALIZATION * float(sum_sq))
    return float(sigma)

def compute_smom_momentum_new(
    prices: pd.Series,
    window: int,
    target_vol: float = TARGET_VOLATILITY,
) -> float:
    """SMOMc(n) = MOMc(n) * (4.5% / σ_n^c)"""
    if len(prices) < window + 1:
        return 0.0
    mom = compute_simple_momentum(prices, window)
    sigma = compute_volatility_sigma_n(prices, window)
    if sigma <= 0:
        return 0.0
    return float(mom * (target_vol / sigma))
```

**差异要点：**
- **波动率窗口**：图片用 **win**（与 MOM 同窗），本端用 **固定 60 日** + **n 日均值**，与编制规则一致。
- **年化**：图片 252，本端 250/60。
- **缩放形式**：均为 `mom * (target_vol / vol)`，一致。

## 三、综合得分与时间窗口

- **综合得分**：本端为 **Score^c = Σ S(MOM,n) + Σ S(MACD,n) + Σ S(POSI,n) + Σ S(SMOM,n)**，与编制规则一致；图片侧未给出加总方式，仅给出各因子 0/1 信号。
- **时间窗口**：本端采用编制规则（MOM/POSI/SMOM: 20,60,120,250；MACD: 40,80,120,160）；图片中为参数 win / win_short / win_long，未固定为上述数列。

**portfilio-end 综合得分与调用处**（`app/selection/formula/advanced_momentum_factors.py`）：
```python
# 默认窗口
DEFAULT_MOM_WINDOWS = [20, 60, 120, 250]
DEFAULT_MACD_WINDOWS = [40, 80, 120, 160]
DEFAULT_POSI_WINDOWS = [20, 60, 120, 250]
DEFAULT_SMOM_WINDOWS = [20, 60, 120, 250]

# 在 compute_advanced_momentum_scores 中：
for w in momentum_windows.get("MOM", DEFAULT_MOM_WINDOWS):
    val = compute_simple_momentum(p, w)
    r[f"S_MOM_{w}"] = trading_signal(val)
# ... 同理 MACD, POSI, SMOM ...
s_cols = [c for c in mom_df.columns if c.startswith("S_") and ...]
mom_df["TotalMomentumScore"] = mom_df[s_cols].sum(axis=1)
```

## 四、实现逻辑解析（要点）与核心代码

以下按因子列出**实现逻辑要点**，并附 **portfilio-end 核心代码**，便于快速对照检查。

### 1. MOM 要点 + 核心代码

- **要点**：MOMc(n) = (TR_t/TR_{t-n}) - 1；信号 S = 1 若 F > -0.02，否则 0。
- **核心代码**（`advanced_momentum_factors.py`）：
```python
def compute_simple_momentum(prices: pd.Series, window: int) -> float:
    if len(prices) < window + 1:
        return 0.0
    return float((prices.iloc[-1] / prices.iloc[-window - 1]) - 1)

def trading_signal(factor_value: float, threshold: float = SIGNAL_THRESHOLD) -> int:
    return 1 if factor_value > threshold else 0  # SIGNAL_THRESHOLD = -0.02
```

### 2. MACD 要点 + 核心代码

- **要点**：本端为**收益率比值** MACDc(n) = (n 期动量)/(250 期动量)，非价格双均线差。
- **核心代码**（`advanced_momentum_factors.py`）：
```python
def compute_macd_momentum_new(prices: pd.Series, window: int, long_window: int = 250) -> float:
    if len(prices) < long_window + 1 or window < 1:
        return 0.0
    mom_n = (prices.iloc[-1] / prices.iloc[-window - 1]) - 1
    mom_250 = (prices.iloc[-1] / prices.iloc[-long_window - 1]) - 1
    if abs(mom_250) < 1e-12:
        return 0.0
    return float(mom_n / mom_250)
```

### 3. POSI 要点 + 核心代码

- **要点**：POSIc(n) = rpos + rneg（正收益和 + 负收益和）= 区间总收益。
- **核心代码**（`advanced_momentum_factors.py`）：
```python
def compute_posi_momentum_new(prices: pd.Series, window: int) -> float:
    if len(prices) < window + 1:
        return 0.0
    returns = _daily_returns(prices).iloc[-window:]
    rpos = returns[returns > 0].sum()
    rneg = returns[returns < 0].sum()
    return float(rpos + rneg)
```

### 4. SMOM 要点 + 核心代码

- **要点**：σ 为 60 日窗口、相对 n 日均值方差、250/60 年化；SMOM = MOM × (4.5% / σ)。
- **核心代码**（`advanced_momentum_factors.py`）：
```python
def compute_volatility_sigma_n(prices: pd.Series, n: int, vol_window: int = 60) -> float:
    returns = _daily_returns(prices)
    r_last = returns.iloc[-vol_window:]
    mean_n = returns.iloc[-n:].mean()
    deviations = r_last - mean_n
    sigma = np.sqrt(VOL_ANNUALIZATION * (deviations ** 2).sum())  # 250/60
    return float(sigma)

def compute_smom_momentum_new(prices: pd.Series, window: int, target_vol: float = 0.045) -> float:
    mom = compute_simple_momentum(prices, window)
    sigma = compute_volatility_sigma_n(prices, window)
    if sigma <= 0:
        return 0.0
    return float(mom * (target_vol / sigma))
```

### 5. 综合得分要点 + 核心代码

- **要点**：TotalMomentumScore = 所有 S_* 列之和；各因子按默认窗口计算 S，再求和。
- **核心代码**（`advanced_momentum_factors.py`）：
```python
# 默认窗口
DEFAULT_MOM_WINDOWS = [20, 60, 120, 250]
DEFAULT_MACD_WINDOWS = [40, 80, 120, 160]
DEFAULT_POSI_WINDOWS = [20, 60, 120, 250]
DEFAULT_SMOM_WINDOWS = [20, 60, 120, 250]

# 单资产循环内对每窗口算因子并生成 S
for w in momentum_windows.get("MOM", DEFAULT_MOM_WINDOWS):
    val = compute_simple_momentum(p, w)
    r[f"S_MOM_{w}"] = trading_signal(val)
# 同理 MACD, POSI, SMOM ...
s_cols = [c for c in mom_df.columns if c.startswith("S_") and ...]
mom_df["TotalMomentumScore"] = mom_df[s_cols].sum(axis=1)
```

## 五、总结表

| 项目 | 图片参考代码 | portfilio-end（编制规则） |
|------|--------------|---------------------------|
| MOM 公式 | (TR_t/TR_{t-n})-1（推断） | (TR_t/TR_{t-n})-1 ✅ |
| MACD 公式 | 价格 short SMA − long SMA | (n 期动量)/(250 期动量) ❌ 不同定义 |
| POSI 公式 | 正和 − \|负和\| = 总收益 | 正和 + 负和 = 总收益 ✅ 等价 |
| SMOM 缩放 | mom × (vol_target/vol) | MOM × (4.5%/σ) ✅ |
| 波动率 σ | rolling(win).std() 年化 | 60 日、(r_i−mean_n)²、250/60 年化 ⚠️ 不同 |
| 信号 | F > th → 1 | F > -0.02 → 1 ✅ |
| 窗口参数 | 由 win 等传入 | 20,60,120,250 / 40,80,120,160（编制规则） |

**结论：**  
- **MOM、POSI、信号规则**：与图片一致或等价。  
- **MACD**：与图片**定义不同**（价格均线差 vs 收益率比值）；本端按编制规则实现，不按图片实现。  
- **SMOM**：缩放思路一致，**波动率计算方式不同**（窗口与中心化按编制规则）。

若需与图片中的“价格双均线差 MACD”或“win 期标准差 SMOM”完全一致，需在 portfilio-end 中增加**另一套实现**并可选切换；当前代码以**编制规则**为准。
