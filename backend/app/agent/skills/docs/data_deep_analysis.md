## 深度数据分析工作流指导

### 标准分析框架

深度分析遵循五阶段标准框架：**数据准备 → 收益分析 → 风险分析 → 相关性分析 → 综合评价**。每个阶段产出明确的量化指标和可视化图表，最终形成结构化的分析报告。

### 第一阶段：数据准备

根据用户输入确定分析目标：
- **明确指定资产代码**：直接使用 `data_query` 查询该资产的价格序列数据。
- **模糊描述**：先用 `data_query(action="discover")` 探索可用集合，再用 `schema` 确认字段结构，定位到正确的资产代码和价格字段。
- **多资产分析**：收集所有目标资产代码，确保时间范围对齐。

日期范围处理：用户未指定时，默认取最近一年数据；用户指定"近三个月"等相对时间时，自动换算为具体起止日期。

### 第二阶段：收益率分析

```
data_analyze(action="returns", asset_codes=[...], start_date="YYYY-MM-DD", end_date="YYYY-MM-DD")
```

- 输出日收益率序列和累计收益曲线数据
- 自动生成累计收益折线图（多资产时叠加在同一图中对比）
- 标注关键时间点：最大单日涨幅、最大单日跌幅

### 第三阶段：风险收益统计

```
data_analyze(action="statistics", asset_codes=[...], start_date="YYYY-MM-DD", end_date="YYYY-MM-DD")
```

输出 10 个核心量化指标：

| 指标 | 说明 |
|------|------|
| 年化收益率 | 几何平均年化收益 |
| 年化波动率 | 日收益率标准差年化 |
| 夏普比率 | 超额收益/波动率 |
| 最大回撤 | 峰到谷最大跌幅 |
| VaR(95%) | 95%置信度在险价值 |
| 偏度 | 收益分布偏斜程度 |
| 峰度 | 收益分布尾部厚度 |
| 胜率 | 正收益交易日占比 |
| 累计收益 | 期间总收益率 |
| Calmar比率 | 年化收益/最大回撤 |

自动生成多指标对比柱状图（多资产时尤为重要）。

### 第四阶段：相关性分析（多资产时执行）

```
data_analyze(action="correlation", asset_codes=[...], start_date="YYYY-MM-DD", end_date="YYYY-MM-DD")
```

- 输出资产间相关系数矩阵
- 自动标注最高相关性对和最低相关性对，帮助用户理解资产间联动关系
- 生成热力图，颜色深浅直观反映相关程度
- 相关系数 > 0.7 标记为"高度正相关"，< -0.3 标记为"负相关/分散化良好"

### 第五阶段：综合评价

基于前四阶段的量化结果，生成结构化的文字评价：
- 总结收益能力（与基准对比）
- 评估风险水平（波动率、回撤是否可接受）
- 给出风险调整后收益评价（夏普、Calmar）
- 多资产时给出分散化建议

### 数值精度规范

- 收益率类指标（%）：保留 2 位小数
- 比率类指标（夏普、Calmar）：保留 3 位小数
- 相关系数：保留 4 位小数
- 波动率（%）：保留 2 位小数
