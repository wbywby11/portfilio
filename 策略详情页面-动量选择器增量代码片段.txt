// 获取选择器名称
getSelectorName(selectorType) {
  const map = {
    'momentum': 'SHARP动量选择器',
    'reversal': '反转选择器',
    'momentum_reversal': '动量-反转混合选择器'
  };
  return map[selectorType] || selectorType || '未知';
}

【关键特性】
----------
1. 条件渲染：仅在 enable_momentum_selection 为 true 时显示
2. 显示6个参数：启用状态、选择器类型、选择资产数量、最小历史数据要求、动量窗口、并列决胜窗口
3. 选择器类型中文映射：momentum → SHARP动量选择器
4. 默认值处理：min_history_days 默认 260 天

【调用关系】
----------
StrategyModelList.vue (策略列表)
  → 点击"查看"按钮
  → 打开 el-dialog
  → 加载 StrategyModelDetail.vue
  → 显示资产选择配置卡片（如果启用）

【数据来源】
----------
通过 Vuex store 的 fetchStrategyModel action 从后端获取
后端 API: GET /api/v1/strategy-models/{model_id}

【显示位置】
----------
在策略详情页面中，位于：
- 基本信息卡片之后
- 策略参数卡片之前
