## 🔗 关联关系图谱

### 核心关联链路

```
┌─────────────────────────────────────────────────────────┐
│                  8大数据域关联关系                        │
└─────────────────────────────────────────────────────────┘

主体域 ──发行──→ 资产域
  │                │
管理             估值/收益/现金流
  │                │
  ↓                ↓
产品域 ←─持仓── 资产域
  │
  ├─被投资─→ 客户域
  │            │
  │          归属
  │            │
  │            ↓
  │         销售域
  │
  ├─交易──→ 交易域
  │            │
  │          交易对手
  │            │
  │            ↓
  │         主体域
  │
  └─风控──→ 风险域
               │
             评级变动
               │
               ↓
            主体域
```

### 关联类型示例

#### 1. 直接关联（外键引用）
```javascript
// 资产的发行人
dwd_ast_info.ISR_ID → dwd_isr_institution.ISR_ID

// 持仓的资产
dwd_ptl_ast_hld.AST_CD → dwd_ast_info.AST_CD
```

#### 2. 间接关联（穿透链路）
```javascript
// 客户→产品→资产→发行人（4层穿透）
CUS0000001 → PORT001 → 019601.IB → ISR000001 (财政部)
```

#### 3. 高度关联（360°视图）
```javascript
// 资产被10个表关联
019601.IB:
  ├─ dwd_ast_info (基础信息)
  ├─ dwd_ast_info_ch (中债估值)
  ├─ dwd_ast_info_zg (中证估值)
  ├─ dwd_ast_yield_info (收益率)
  ├─ dwd_ast_cf_plan (现金流)
  ├─ dwd_ast_pledge (质押)
  ├─ dwd_ast_fiveclass (五级分类)
  ├─ dwd_ast_exe_plan (行权)
  ├─ dwd_ast_party (参与方)
  └─ dwd_ptl_ast_hld (被持有)
```

#### 4. 重度关联（一对多）
```javascript
// 产品持有多个资产
PORT001 → [019601.IB, 230210.IB, 2480006.IB, 600036.SH, 510300.SH, 511260.SH, 112311.SZ]

```

#### 5. 轻度关联（可选）
```javascript
// 只有部分资产有质押
5/12 资产有质押信息

// 只有部分资产有行权计划
3/12 资产有行权计划
```
