### 场景 4-7: 进阶场景（v2新增）

#### 场景 4: 交易成本分析
**问题**: PORT001 过去一个月的交易成本对收益的影响？

**分析链路**:
```
dwd_trn_trade_ptl (交易记录)
  ↓ 筛选 PORT_ID='PORT001' AND TRADE_DT > '20250224'
  ↓ 汇总 BROKER_FEE + STAMP_TAX + TRANSFER_FEE
  ↓ 对比 dwd_ptl_nav_history 的净值变化
  
结果:
- 交易总额: 2.5亿
- 交易成本: 25万 (0.1%)
- 净值增长: 0.25%
- 净收益: 0.15% (扣除成本后)
```

#### 场景 5: 财务健康度评估
**问题**: 哪些发行人的财务指标出现恶化？

**分析链路**:
```
dwd_isr_institution_finance
  ↓ 筛选 NET_PROFIT < 0 OR OPERATING_CASH_FLOW < 0
  ↓ 计算 DEBT_RATIO, CURRENT_RATIO, INTEREST_COVERAGE
  ↓ 关联 dwd_crdt_rating_change 查看评级变化
  ↓ 关联 dwd_ast_pledge 查看质押率变化

发现:
- ISR000005 (万科): 
  - 净利润: -150亿
  - 经营现金流: -500亿
  - 资产负债率: 80%
  - 评级: AA → AA- (下调)
  - 质押率: 0% (不可质押)
  
预警信号: ⚠️⚠️⚠️
```

#### 场景 6: 销售绩效分析
**问题**: 哪个销售人员的客户投资偏好最健康？

**分析链路**:
```
dwd_seller_info
  ↓ JOIN dwd_cust_info ON SELLER_ID
  ↓ JOIN dwd_cust_ptl_hld ON CUSTOMER_ID
  ↓ JOIN dwd_ptl_info ON PORT_ID
  ↓ 计算: 客户数、AUM、平均风险等级、产品收益

结果:
- SEL00001 (刘洋):
  - 客户数: 3
  - AUM: 6700万
  - 平均风险等级: C3.3 (偏高风险)
  - 产品平均收益: 5.2%
  
- SEL00002 (赵丽华):
  - 客户数: 1
  - AUM: 1800万
  - 平均风险等级: C2 (稳健)
  - 产品平均收益: 2.85%
  
结论: 刘洋业绩更好，但风险偏好更高
```

#### 场景 7: 历史表现与基准对比
**问题**: PORT001 是否跑赢基准？

**分析链路**:
```
dwd_ptl_nav_history
  ↓ 筛选 PORT_ID='PORT001'
  ↓ 计算: 30天收益率、年化收益率、最大回撤
  ↓ 对比 BENCHMARK (中债综合指数*70%+沪深300*30%)
  
计算:
- 30天收益率: (1.0512 - 1.0485) / 1.0485 = 0.257%
- 年化收益率: 0.257% × 365/30 = 3.13%
- 最大回撤: -0.15% (20250305)
- 波动率: 0.08%

基准:
- 30天收益率: 0.20%
- 年化收益率: 2.45%

结论: PORT001 跑赢基准 0.68%/年 ✓
```

### 场景 8-11: 高级场景（v2新增）

#### 场景 8: 交易对手集中度风险
**问题**: 是否存在对单一交易对手的过度依赖？

**分析链路**:
```
dwd_trn_trade_ptl
  ↓ GROUP BY CNTP_ID
  ↓ SUM(TRADE_AMT) AS total_trade
  ↓ 计算占比: total_trade / SUM(all TRADE_AMT)
  
发现:
- CNTP00001 (中信证券): 45% (超标!)
- CNTP00002 (华泰证券): 25%
- CNTP00003 (国泰君安): 20%
- CNTP00004 (招商证券): 10%

预警: CNTP00001 占比超过30%限制 ⚠️
```

#### 场景 9: 估值差异套利机会
**问题**: 中债和中证估值是否存在套利机会？

**分析链路**:
```
dwd_ast_info_ch (中债)
  ↓ JOIN dwd_ast_info_zg (中证) ON AST_CD + BIZ_DT
  ↓ 计算: ABS(中债估值 - 中证估值)
  ↓ 筛选: 差异 > 0.1%
  
发现:
- 019601.IB: 差异 0.028% (正常)
- 230210.IB: 差异 0.045% (正常)
- 112311.SZ: 仅中证估值 (中债无)

结论: 无明显套利机会
```

#### 场景 10: 现金流匹配分析
**问题**: 产品未来现金流是否能覆盖客户赎回？

**分析链路**:
```
dwd_ast_cf_plan (资产现金流)
  ↓ JOIN dwd_ptl_ast_hld ON AST_CD
  ↓ 筛选 PORT_ID='PORT001'
  ↓ SUM(CF_AMT * HLD_RATIO) AS expected_cashflow
  
dwd_cust_ptl_hld (客户持仓)
  ↓ 筛选 PORT_ID='PORT001'
  ↓ 预估赎回率 10%
  ↓ SUM(HLD_AMT * 0.10) AS expected_redemption
  
对比:
- 未来30天预期现金流: 8000万
- 预期赎回金额: 8000万 (8亿 × 10%)
- 覆盖率: 100% ⚠️ (刚好覆盖，需警惕)
```

#### 场景 11: 五级分类迁徙分析

dwd_ast_fiveclass

### 5.3 数据真实性规则

   - 收益率↑ → 价格↓
   - 久期越长，价格波动越大
   - 凸性始终为正

2. **收益率层次**:
   ```
   国债 (1.95%) < 政金债 (2.65-2.82%) < 商业银行债 (3.10%) < 企业债 (4.50%)
   ```

3. **财务指标合理性**:
   - 资产负债率: 40-85%
   - 流动比率: 0.8-2.5
   - 利息覆盖率: 1.5-10

4. **净值变化**:
   - 日波动: -0.5% ~ +0.5%
   - 累计偏差: ±5% (30天)
