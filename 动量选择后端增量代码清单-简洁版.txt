【关键参数】（6个）
------------------
- enable_momentum_selection: 是否启用动量选择
- selector_type: 选择器类型（momentum/reversal/hybrid）
- asset_selection_count: 选择资产数量（1-100，默认8）
- min_history_days: 最小历史数据要求（100-500，默认260）
- momentum_windows: 动量窗口（如"22,65,260"）
- tie_break_window: 并列决胜窗口（5-260，默认22）

【核心功能】
----------
1. 资产选择模块：完整的selection模块，支持选择器注册和管理
2. 动量选择器：基于多窗口夏普动量的资产筛选
3. 回测集成：StrategyAdapterWithSelection适配器，在回测时执行资产选择
4. 参数覆盖：回测时支持前端参数覆盖模型配置

【数据流】
--------
创建策略：前端 → API → MongoDB（保存动量选择器参数）
回测：前端请求 → 合并参数（请求>模型>默认） → 资产选择 → 策略计算权重
