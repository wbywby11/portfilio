大类资产研究助手（AgentChatPanel）离线安装说明
============================================

本目录包含两个 npm 包 tarball（与 portfilio 工程 package.json 版本一致）：

  - marked-4.3.0.tgz      Markdown 解析（AgentChatPanel.vue 使用 import { marked } from 'marked'）
  - dompurify-3.0.6.tgz   HTML 消毒（import DOMPurify from 'dompurify'）

一、拷入内网
------------
将整个文件夹「offline-npm-bundles」复制到内网前端项目根目录旁任意可读位置
（例如 D:\理财子相关\ZYLCTZZH-QD\third_party\offline-npm-bundles\）。

二、在内网项目根目录执行（PowerShell 或 CMD）
--------------------------------------------
cd /d D:\理财子相关\ZYLCTZZH-QD

:: 若 package.json 中尚无 marked、dompurify，安装命令会自动写入 dependencies
npm install .\third_party\offline-npm-bundles\marked-4.3.0.tgz .\third_party\offline-npm-bundles\dompurify-3.0.6.tgz --save

:: 若你把 tgz 放在项目根目录下的 offline-npm-bundles 子目录，则改为：
:: npm install .\offline-npm-bundles\marked-4.3.0.tgz .\offline-npm-bundles\dompurify-3.0.6.tgz --save

:: 若遇 peer 依赖冲突，可追加：
:: npm install ... --legacy-peer-deps

三、验证
--------
1. 确认 node_modules\marked 与 node_modules\dompurify 存在。
2. 确认 package.json 的 dependencies 中出现 marked、dompurify。
3. npm run dev 重新编译，浏览器控制台不应再出现 marked is not defined。

四、若 npm install 仍报 Maximum call stack size exceeded
--------------------------------------------------------
1. 删除内网项目的 node_modules 与 package-lock.json 后重试（先备份 lock）。
2. 升级 npm：npm install -g npm@9
3. 仍失败时：仅手工将两枚 tgz 解压到 node_modules（不推荐），或换用内网私服 / pnpm 离线源。

五、路径说明
------------
请将上文「third_party\offline-npm-bundles」替换为你实际放置 tgz 的相对路径；
npm install 的参数必须是「指向 .tgz 文件」的有效相对或绝对路径。
