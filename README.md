# 智能投研系统

一个专业的大类资产配置研究、模拟组合管理与业绩分析的一体化投研平台。

## 🎯 系统特点

- **策略研发标准化**：统一资产配置策略研发流程，积累策略知识库
- **组合管理规范化**：实现模拟组合的规范建仓、再平衡与业绩归因
- **投资决策数据化**：基于数据的投资决策支持与回溯分析
- **团队协作高效化**：研究员与投资经理的协同工作平台

## 🛠️ 技术栈

- **前端框架**: Vue 2.6.14
- **构建工具**: Webpack 5
- **UI组件库**: Element UI 2.15
- **状态管理**: Vuex 3.6
- **路由管理**: Vue Router 3.5
- **图表库**: ECharts 5.4
- **HTTP客户端**: Axios
- **工具库**: Day.js, Lodash

## 🔧 核心功能演示

### 资产库管理

1. 进入"资产库管理" → "资产列表"
2. 点击"新增资产"，填写资产信息
3. 支持设置风险等级、预期收益率、波动率等参数
4. 资产分为5大类：权益类、固定收益类、商品类、另类资产、现金类

### 策略开发

1. 进入"策略管理" → "算法模板库"
2. 选择合适的算法模板（如"均值方差模型"）
3. 点击"使用模板"进入策略开发界面
4. 左侧选择资产，中间配置参数，右侧查看结果
5. 点击"运行计算"得到权重分配
6. 保存策略供后续使用

### 组合创建

1. 进入"模拟组合" → "创建组合"
2. 填写组合基本信息（名称、初始资金、基准等）
3. 选择建仓方式：
   - 手工建仓：手动添加持仓
   - 模型关联：选择策略自动生成持仓
4. 确认信息后创建组合

## 📊 数据模型

### 资产模型
```javascript
{
  id: Number,          // 资产ID
  code: String,        // 资产代码
  name: String,        // 资产名称
  category: String,    // 资产分类
  riskLevel: Number,   // 风险等级(1-5)
  expectedReturn: Number, // 预期收益率
  volatility: Number,  // 波动率
  liquidity: String,   // 流动性(high/medium/low)
  status: String       // 状态(active/inactive)
}
```

### 策略模型
```javascript
{
  id: String,          // 策略ID
  name: String,        // 策略名称
  templateId: String,  // 模板ID
  assets: Array,       // 资产列表
  parameters: Object,  // 参数配置
  result: {            // 计算结果
    weights: Object,   // 权重分配
    expectedReturn: Number,
    expectedRisk: Number,
    sharpeRatio: Number
  }
}
```

### 组合模型
```javascript
{
  id: String,          // 组合ID
  name: String,        // 组合名称
  initialCapital: Number, // 初始资金
  totalValue: Number,  // 当前市值
  totalReturn: Number, // 累计收益率
  status: String,      // 状态(active/paused/archived)
  holdings: Array,     // 持仓明细
  benchmarks: Array    // 业绩基准
}
```
