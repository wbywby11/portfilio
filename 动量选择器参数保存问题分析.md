# 动量选择器参数保存问题分析

## 问题描述
前端保存策略模型后，后端没有保存动量选择器相关的参数。

---

## 相关代码文件

### 1. 前端提交代码
**文件**: `portfilio/src/views/strategy/StrategyModelForm.vue`
**位置**: 第616-631行

```javascript
const modelData = {
  name: this.form.name,
  description: this.form.description,
  template_code: this.form.template_code,
  asset_codes: this.form.asset_codes,
  parameters: submitParameters,
  rebalance_frequency: this.form.rebalance_frequency,
  // 新增字段：资产选择策略相关
  enable_momentum_selection: this.form.enable_momentum_selection,
  selector_type: this.form.enable_momentum_selection ? this.form.selector_type : '',
  asset_selection_count: this.form.enable_momentum_selection ? this.form.asset_selection_count : 1,
  // 新增：动量资产选择相关参数提交
  min_history_days: this.form.enable_momentum_selection ? this.form.min_history_days : 260,

  tie_break_window: this.form.enable_momentum_selection ? this.form.tie_break_window : 22
```

**问题点**: 
- 当 `enable_momentum_selection` 为 `false` 时，`selector_type` 被设置为空字符串 `''`
- 空字符串可能被 Pydantic 视为无效值或默认值，导致不保存

## 问题分析

### 可能的原因

1. **Pydantic 默认行为**
   - `model.dict()` 默认 `exclude_none=False`，但空字符串可能被视为无效值
   - 如果字段值为空字符串 `''`，可能不会被包含在字典中

2. **前端传递空字符串**
   - 当 `enable_momentum_selection` 为 `false` 时，`selector_type` 被设置为 `''`
   - 空字符串可能被 Pydantic 忽略或验证失败

3. **更新时使用 `exclude_unset=True`**
   - 如果字段在前端被设置为 `None` 或空字符串，可能被视为"未设置"
   - 导致这些字段不会被更新到数据库

---

## 解决方案

### 方案1: 修改前端，不传递空字符串
**文件**: `portfilio/src/views/strategy/StrategyModelForm.vue`

```javascript
const modelData = {
  // ... 其他字段
  enable_momentum_selection: this.form.enable_momentum_selection,
  // 修改：不传递空字符串，而是传递 undefined 或不传递该字段
  ...(this.form.enable_momentum_selection ? {
    selector_type: this.form.selector_type,
    asset_selection_count: this.form.asset_selection_count,
    min_history_days: this.form.min_history_days,
    momentum_windows: this.form.momentum_windows,
    tie_break_window: this.form.tie_break_window
  } : {})
};
```

### 方案2: 修改后端，显式包含所有字段
**文件**: `portfilio-end/app/api/strategy_model.py`

```python
# 创建时
model_data = model_in.dict(exclude_none=False)  # 显式包含 None 值
# 或者
model_data = model_in.dict(exclude_unset=False, exclude_none=False)

# 更新时
update_data = model_update.dict(exclude_unset=False, exclude_none=False)  # 包含所有字段
```

### 方案3: 修改服务层，确保保存所有字段
**文件**: `portfilio-end/app/services/strategy_model_service.py`

```python
async def create_model(self, model: StrategyModel) -> str:
    """创建模型"""
    model_dict = model.dict(by_alias=True, exclude={'id'}, exclude_none=False)  # 包含 None 值
    result = await self.collection.insert_one(model_dict)
    return str(result.inserted_id)
```

### 方案4: 在 API 层显式处理
**文件**: `portfilio-end/app/api/strategy_model.py`

```python
@router.post("/", response_model=Response[str], summary="创建策略模型")
async def create_model(...):
    # ...
    model_data = model_in.dict(exclude_none=False)
    model_data.pop('benchmark_code', None)
    
    # 显式处理动量选择器字段
    if 'enable_momentum_selection' in model_data:
        # 确保所有相关字段都被包含
        if model_data.get('enable_momentum_selection'):
            # 启用时，确保所有字段都有值
            if not model_data.get('selector_type'):
                model_data['selector_type'] = 'momentum'
            if not model_data.get('asset_selection_count'):
                model_data['asset_selection_count'] = 1
            # ... 其他字段的默认值
        else:
            # 未启用时，可以设置为 None 或删除
            model_data['selector_type'] = None
            # ... 其他字段设置为 None
    
    model = StrategyModel(**model_data)
    # ...
```

## 推荐解决方案

**推荐使用方案1 + 方案3的组合**：

1. **前端修改**：只在启用选择器时传递相关字段，未启用时不传递
2. **后端修改**：在服务层使用 `exclude_none=False` 确保包含所有字段

这样可以：
- 避免传递空字符串导致的验证问题
- 确保数据库中有明确的字段值（即使是 `None`）
- 保持代码清晰和可维护
